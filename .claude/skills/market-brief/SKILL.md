# /market-brief — 市場定点観測（1起動＝1ブリーフ）

決定論的コアは `examples/market_brief.py`（読み取り専用・ネットワーク不要・欠損は WARN で劣化継続）。
出力 JSON は `output/market_brief/brief_{YYYYMMDD}.json` に蓄積され、**前回比較の材料**になる。

## ガードレール（違反不可）

1. **数値はコードが正**。LLM が独自に再計算・補正しない（解釈と比較のみ）。
2. **裁量レーン**: このブリーフとその解釈を research_loop/・docs の事前登録・レジストリの
   設計根拠に使わない。研究に載せたい観察が出たら「IDEAS 候補として /research-scout で
   別途スクリーニングする」ことを提案するに留める（自分では書かない）。
3. 書き込み先は `output/` のみ。git コミットはしない（output/ は gitignore）。
4. **鮮度ゲート**: 各セクションの date が asof より7日以上古ければ、解釈より先に
   「`/data-update` の実行が先」と報告する（古いデータの解釈は誤誘導）。

## 手順

### Step 1 実行
```powershell
$env:PYTHONUTF8="1"; .\.venv\Scripts\python.exe examples\market_brief.py
```
過去日の再現は `--asof YYYY-MM-DD`。

### Step 2 前回との比較
`output/market_brief/` の直近の brief_*.json（今回分の1つ前）を読み、主要項目の差分を取る:
セクターRS上位/下位の入替・フロー z の符号転換・信用 short_to_long 分位・IV/skew/term 分位・
60日線上業種比率・USDJPY/金利。初回実行で前回が無ければ「基準日」として水準のみ報告。

### Step 3 Web で最新文脈を補完（必須）
ローカルミラーには数日の遅延があり得るため、WebSearch で「今」を必ず足す:
①当日〜直近の日本市況ニュース（急騰/急落の理由・主導セクター） ②日銀・政府・規制の
新着発言/決定 ③海外市場の直近動向（米・中・為替） ④スクリプト数値と矛盾する急変の有無。
レポートでは「数値は X 日時点・文脈は本日」と時点を分けて書く。

### Step 4 解釈レポート（1画面）
- **市場状態3行**: リスク選好（IV分位×RS の攻守どちらの業種が上位か）・需給（海外/個人の向き）・
  トレンド（52週高値距離・60日線上比率）。
- **変化点**: 前回から動いたものだけ列挙（動いていない項目は書かない）。
- **スリーブへの含意（観察であり指図ではない）**: value↔PEAD switch・TSMOM それぞれに
  追い風/向かい風の観察を1行ずつ。執行判断は /tactical-brief・人間の領分。
- **注視点**: 次回ブリーフまでに確認すべきイベント（決算集中週・日銀/FOMC 等は既知範囲で）。

## 運用メモ
- 推奨頻度: 週次〜任意（フローと信用は週次更新なので毎日回しても [2][3] は動かない）。
- 毎朝の自動化は /schedule で `claude -p "/market-brief"` を登録すればよい（人間が設定）。
- 業種指数の名称は上場マスタ S33 順から導出。WARN が出た場合は生コード表示に落ちる。
