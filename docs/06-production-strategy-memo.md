## 1. 戦略の仕組み — なぜ儲かると考えるか

### 1.1 中核の発見：value だけが生き残った
10年・全銘柄で多数のファクターを検証した結果、**生存者バイアスを正しく除去すると、耐久エッジを
残したのは value（割安, book-to-market）のみ**だった。有望に見えた size（小型株）・
short_to_long（信用）は、**固定ユニバースが生んだ生存者バイアスの産物**で、時変ユニバース（PIT）に
切り替えると DSR 0.82→0.35、0.68→0.24 と崩壊した（§2.4/§6.3）。
ただし value 単独は **年率Sharpe ≈0.36 と低く、認定に必要な履歴（minTRL≈20年）に対し10年では不足**
（§7.1）。「本物らしいが単独では未証明」が出発点である。

### 1.2 増幅機構：value と PEAD は「ボラ依存が逆」
value（割安）と PEAD（会社予想の改訂後ドリフト）の、市場ボラ・レジーム別の成績を建玉前に
診断したところ、**明確かつ逆向きの分離**が出た（§6.9）:

| | 低ボラ(平常) | 中 | 高ボラ(混乱) |
|---|--:|--:|--:|
| **value × ボラ** | +1.21 | +0.88 | **−1.04**（劣後） |
| **PEAD × ボラ** | −0.76 | −0.52 | **+1.52**（優位） |

経済的物語が明快である — 平常時は割安株が報われ、**flight-to-quality の混乱期はバリューが叩かれる**。
逆に不確実性が高い局面ほど**予想改訂（PEAD）の情報価値が増す**。

### 1.3 旗艦戦略：レジームで両者を切り替える
この逆相関を利用し、**「平常(vol≤1)=value、混乱(vol==2)=PEAD」を ≤t のレジームで切り替え**る
一本のスリーブに束ねた（`RegimeSwitch`・PIT）。value が現金待機する高ボラ月を、ちょうど PEAD が
埋める**相補構造**である（§6.10）。PEADはショート脚が value のロング（割安・ディストレス株）と
正面衝突して脆かったため、**ロングティルト化**（上位ロング×市場ヘッジ、下位を名指しで売らない）で
診断駆動の修正を施している（§7.2–7.3）。

### 1.4 オーバーレイ：マルチアセットTSMOM（分散スリーブ）
株式スリーブ（平時に強く危機に弱い）と**逆の非対称性**を持つ分散源として、時系列モメンタム
（11資産・先物/CFD）を重ねた（§6.15）。狙いは単体収益でなく分散効果 — 実測相関は **−0.06**、
COVID期に **+2.3%（対 日経 −5.1%）の危機アルファ**を実現している。

### 2.3 期待リターンと損失可能性（執行現実性込み — ここが最重要）
紙上の数字は楽観的である。**日足データの3つの罠（同足先読み・寄りギャップ・流動性偏り）と
貸株コストを全て織り込んで再測定**した（§6.13）。判断は下表の現実帯で行うべきである:

| シナリオ（全部入りに向け段階追加） | 旗艦 SR(全/OOS) |
|---|--:|
| A: 同足終値・15bp固定（バックテストの素の値） | +0.97 / +0.94 |
| B: **T+1始値**・15bp固定 | +0.90 / +0.82 |
| C: T+1始値・ボラ連動スリッページ(中庸) | +0.84 / +0.72 |
| D: + ボラ連動(保守) | +0.72 / +0.55 |
| **E: D + 貸株115bp（全部入り・最悪セル）** | **+0.62 / +0.45** |

- **計画基準**: B〜C帯 = **年率SR +0.75〜0.90 / OOS +0.72〜0.82**。
- **下限**: 全部入りEでも **OOS +0.45 で正** — 日足の甘さに対して結論は生存。
- **損失可能性**: バックテスト最大DDは旗艦単体 −8.3% / 合成 −5.4%。**運用上のハード限度は
  キルスイッチ（元本基準DD: 警報−8% / デリスク−12% / 停止−15%）**で管理。
- **binding constraint は荒れ相場の取引コスト**（ボラ連動スリッページ）。単独PEADは保守ケースで
  負に沈むが、合成は分散で吸収。

### 2.4 レバレッジ・容量
- **レバレッジはフラクショナル・ケリーで導出**（§6.12, DP16）。全部入りE基準でクォーターケリー
  f≈1.6。**等倍（レバ1.0）開始はケリー上限の1/4未満**で構造的に過大賭けの余地なし。実運用では
  ハードDD限度が拘束。
- **容量約¥6億**（最も薄い建玉が participation×ADV に達するAUM）。本番開始は〜¥50万〜¥100万の
  ため容量制約は無関係。ショート脚の貸借カバレッジは平均95.4%。

## 3. なぜこの数字を信じられるか — 検証の厳密性

このリポジトリの価値は「儲かる戦略」ではなく「**偽陽性を構造的に排除する検証装置**」である。
本候補は以下の多重フィルタを通過している:

1. **先読みの構造的遮断** — `AsOfView` が戦略に「基準日以前」しか見せず、未来バー参照が物理的に
   不可能。ユニバースもPITで時変選抜（生存者バイアス除去）。
2. **選択バイアスの罰則（永続デフレートDSR）** — 26 scope・累計711試行をSQLiteに累積。
   パラメータ格子の各点も独立試行として計数し、**試行を増やすほど合格基準が上がる**
   （「通るまで回す」が効かない）。**全試行で偽アルファ生成ゼロ**。
3. **実装リスクの裏取り** — 旗艦を `engine.py` 非依存の独立純Pythonで再計算 → **機械精度(8.3e-17)
   で一致**（§6.20）。さらに自前ファクターを Kenneth French 日本ファクターと突合 →
   value vs HML **corr +0.77**、momentum vs WML **corr +0.74** ⇒ **財務PIT・調整係数・ユニバース
   構築にバグの兆候なし**。
4. **walk-forwardで過学習懸念を解消** — 静的割当（value@平常/PEAD@混乱）を、各時点で過去のみから
   学習し直しても **86%再発見**・DSR 0.97維持 ⇒ パターンは安定で過去から学習可能=in-sample設計の
   産物ではない（§6.11）。
5. **執行現実性を一級市民に** — 値幅制限の張り付き・貸株コスト・T+1始値・ボラ連動スリッページを
   全てエンジンに常設。

## 4. 正直な限界とリスク（隠さず記載）

責任者の判断のため、誇張せず限界を明示する（§9）:

1. **DSRはscope局所値（K=4）であり、多重検定族を広げると認定は成立しない**（2026-06-11 実測・
   docs/03 §6.27）。報告の DSR 0.99 は「switch 変種4本だけを多重検定族とみなした」値。株式
   スリーブの月次ファクター候補として**実際に競合した61試行で公正にデフレートすると、switch の
   DSR は 0.99→0.21（観測分散）〜0.78（帰無ノイズ分散）に低下し、いずれも0.95未達**。実際、
   旗艦の年率SR +0.97 は「61試行から選んだ最良がノイズで到達しうる天井（+1.2/年）」を下回る。
   ＝**現10年標本では、どの公正な勘定でも統計的認定は成立しない**（§7.4/§9 の留保を数値で確定）。
   旗艦/合成が0.97–0.99に見えるのは scope 局所の産物。**認定の唯一の道はフォワードでの履歴蓄積**。
2. **割当設計に一部 in-sample 要素**。レジーム割当は全期間breakdown由来で、OOS期間も診断に含む=
   完全なholdoutではない。walk-forwardで大部分は解消したが、**真の最終検証は将来データ（2026-05
   以降）のフォワードのみ**。
3. **10年では低Sharpe単一因子を認定できない**（minTRL≈20年）。これは日本株ファクター投資の
   現実であり、装置の欠陥ではない。
4. **データ制約**: 信用残高は週次止まり、決算発表予定は履歴なし、詳細財務・先物建値はPremium、
   ニュースは外部。スリッページは日足proxyであり実測ではない — **最終較正は実約定での
   live-vs-backtest突合でしか得られない**。
5. **改善のpost-2020集中**: 合成の改善は2020年以降に集中（pre-2020はTSMOMのCTA winterがドラッグ）。
   「常勝合成」ではなくレジーム補完。

## 5. 本番移行計画と意思決定事項

**現状（Phase 2a 紙トレ）はすでに稼働中**（§10）:
- **2026-06 開始・資本〜¥100万・楽天証券前提**。月次注文リストを `phase2_generate_orders.py` で
  自動生成（ロング=かぶミニ寄付=T+1始値、ショート脚=日経225マイクロ売り集約）。**0.25%の
  リバランス・デッドバンドを採用済**（微調整コストのみ削り、シグナルは殺さない）。
- **無人運用の配管が稼働**（2026-06-11〜）: 毎晩21:30 JSTにGitHub Actionsがデータ更新→注文生成→
  照合→Supabase同期→Vercel自動デプロイ。キルスイッチと計画帯を月次レポート化。
- **小資本のトラッキングエラーが紙トレの主要計測対象**（初回実測で値がさ株13銘柄が1株も買えず脱落）。

| # | 意思決定 | 備考 |
