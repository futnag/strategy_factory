## 3. 解釈（記述・断定しない）
- **典型例（中央値）の超過ドリフトは全ホライズンでほぼ 0、勝率 ~49–51%＝コインフリップ**。
  一方で**平均超過は正で時間とともに拡大**（+1.2%→+8.9%@120d）。両者の乖離＝期待値は
  **少数の大当たり（右に厚いテール）に依存**し、銘柄ごとの安定したエッジではない。
  確定事項 3 の「小サンプル・少数大当たりリスク」を実データが裏づけた。
- **スタイル別**：hard も soft も中央値超過は ~0。soft の長期平均がやや高い（+6.3%@120d・
  n=28）が小 N でテール駆動。スタイルで明確な序列は立たない。
- **保有割合帯**：母集団の主力 5–10%（n=211）は中央値超過がわずかに正（+0.5〜+1.2%・
  勝率 51–52%）。限界的。10–20%/20–30% は小 N でノイズ。
- **年（レジーム）依存が大きい**：2022 コホートのみ突出（中央値超過 +4〜7%・勝率 59–67%）。
  2023–2026 は中央値フラット〜マイナス。単純プールは禁止（PIT 地雷 #3 と同型の規律）。
- **選択バイアス（保守側）**：120d カバレッジ 178/247。buyout/TOB 成立で delist した銘柄
  （テールの大当たり候補）が長期窓で脱落＝**平均を下方に偏らせる**。中央値 ~0 はこの偏りに
  頑健。

## 4. 申し送り（Phase 2・docs/07 C2 / docs/10 §5 へ）
- ブロードな「新規 5%→ドリフト」は本窓（2022–2026）で**系統的エッジを示さない**（中央値超過
  ≈0）。期待値はイベント条件付き（後続のエスカレーション＝取締役選任提案・委任状争奪・TOB
  への発展）に宿る可能性が高い。次の検証は **エントリー後イベントで条件付け**た部分集合
  （例：同一銘柄での買い増し＝変更報告 010002、複数アクティビスト同時参入）に絞るのが筋。
- 厳格 DSR には載せない（小サンプル・テール依存・レジーム依存）。**Phase 2 フォワードスリーブ**
  で前向きに積み増し、テールの源泉（どの参入が大当たりになるか）の事前特徴量を探す。
- データ拡張の選択肢：(a) 変更報告 010002 を取り込み「買い増し」イベントを母集団化、
  (b) 2016–2021 を M&A Online で接続しレジーム頑健性を見る（docs/10 §6.2・手動）。
