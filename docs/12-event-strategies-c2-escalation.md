## 2. 台帳エントリー（確定知見・再検証なしで参照可）

### 2.1 【確定知見・禁忌】高保有到達（≥10%/≥20%）への追随は危険
- **保有割合が初めて 10–20% を超えた報告の後、前方は中央値マイナス**（≥20%・全体 x60 **−4.7%**、
  現行 2023-2026 で **x60 −5.82%・勝率33%**）。仮説（高保有＝本気度）と**逆**。
- 解釈：10–20% への積み増し過程で株価は既に反応済み＝**到達時点では織り込み完了、以後フェード**。
- **資産としての扱い**：「高保有到達を買いシグナルにする素朴戦略」は**本台帳で却下済み**＝
  将来これを再提案する場合は**再検証でなくまず本エントリーを参照**。ロング登録しない（K も払わない＝
  そもそも棄却）。むしろ逆張り/手仕舞いの状況証拠として保持。

### 2.2 登録しない条件
- **① 買い増し**：2021-2022 のみ x60 +3.44% だが**現行 2023-2026 で消失（+0.14%）**＝レジーム依存で
  robust でない（docs/11 と同型）。フォワード登録しない。
- **⑤ hard スタイル**：docs/11 のスタイルカットを**追認**（x5 +0.63 / x60 −0.62＝エッジ弱い）。
  独立シグナルでない（位置づけどおり）。登録しない。

### 2.3 唯一の芽：② 複数アクティビスト同時参入 → §3 で Phase 2 事前登録
- 4条件で**唯一、正でレジーム持続的**（x60 中央 +5.8%・勝率 75–79%・現行 2023-2026 でも維持）。
  経済的にも筋（2人目の参入が命題を検証・圧力増）。**ただし N=17 で過小検出力**。

## 3. ② 複数アクティビスト — Phase 2 フォワードスリーブ事前登録メモ

registry scope `c2_escalation_multi`（status=preregistered・**結果は将来フォワードで record**。
本日時点は a-priori 理論の凍結のみ＝trial_count に算入せず K を汚さない）。

### 3.1 単一仕様（凍結・後から変えない）
- **イベント定義**：同一 issuer に対し、コア母集団（new×重要提案・5–30%）の**2 グループ目以降**の
  新規大量保有報告（直前に別の canonical_group が **365 日以内**に新規報告済み）。
- **イベント日**：2 件目以降の**提出日**（T+1 始値エントリー・PIT）。
- **ホライズン**：**20 取引日 と 60 取引日を併記**（下記 3.3）。
- **評価**：TOPIX 超過の**中央値**・勝率（平均はテール駆動で不採用）。等加重・サブ期間別。
- **母集団・registry は不変**（タグ補修のみ可）。

### 3.2 仮説と経済的合理性
- 仮説：単独参入（docs/11 で中央超過≈0）と異なり、**複数アクティビストの同時参入は命題の
  独立検証＋経営への圧力増**となり、即時織り込みを超えた持続ドリフトを生む。
- 合理性：2 人目の参入は (i) 1 人目のバリュー命題を第三者が追認、(ii) 委任状・株主提案での
  連携可能性、(iii) M&A・非公開化の対象としての注目度上昇、を示唆。触媒は AGM サイクル・
  提案/交渉を通じ**数ヶ月かけて**顕在化する。

### 3.3 ホライズン選択の根拠（後知恵の排除）
- 経済仮説はキャンペーン触媒の顕在化＝**1〜3 ヶ月の多月ホライズン**を支持。5 取引日（即時再評価
  のみ）は短すぎ＝除外。
- **ただし 60 を 20 より優先する経済的根拠はない**（データ上 60 が最大なのを理由に 60 を選ぶのは
  後知恵＝in-sample ホライズン選択）。→ **20 と 60 を併記**してフォワード観察（どちらが効くかは
  事前に決めず、フォワードのサンプルで判断・将来 K を払って厳格化）。

### 3.4 選択バイアスの未解明（明記・フォワードで観察）
- **複数参入は「明白な機会（誰の目にも割安/イベント性が高い銘柄）」と交絡**しうる。観測された
  +5.8% が「複数参入というシグナル」由来か、「もともと織り込みが進む銘柄に複数が群がっただけ」
  （既織り込みの選択効果）かは**本データで分離できていない**。
- フォワードで観察すべき：**2 件目参入時点の既織り込み度**（1 件目参入〜2 件目参入の間の累積超過
  リターン）と、その条件付きで前方ドリフトが残るか。既に大きく動いた後なら ③ 同様フェードに
  転じる懸念。

### 3.5 検出力と裁定の留保
- 現時点 N=17（参考）。**厳格 DSR はしない**＝フォワードでイベントを積み増し、十分な N に達した
  段階で**将来 K を払って一発判定**。後知恵の閾値追加・事後の窓選択は封印（K 規律）。

## 4. この検証で台帳に刻まれた結論
**「アクティビスト追随は、ブロードでも個別エスカレーションでも個人投資家には取りにくい。
4 条件のうち芽があるのは ② 複数アクティビスト同時参入のみ（小 N・要フォワード）、③ 高保有到達は
逆に危険（追随の禁忌）。」** ①⑤は不登録。これは規律（事前凍結・母集団不変・記述のみ・PIT）を
保った結論であり、将来の素朴戦略の再検証を不要にする。
