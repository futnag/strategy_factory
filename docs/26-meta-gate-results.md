## 4. なぜ失敗したか（メカニズムの解釈）

- スケールは [0,1]＝露出を**減らす**ことしかできない。にもかかわらず IS が +0.25 → **−0.40**
  と負化した。これは単なる縮小では起こらない＝**ゲートが「勝ち月を絞り・負け月を残す」逆位相の
  誤タイミングを学習**したことを意味する（スケールがリターンと負相関）。
- 原因は**一次戦略の非定常性**。ungated は 2016–19 で −0.42（不調）→ 2019–23 +0.53 → 2023–26
  +0.60（好調）と局面で性質が反転している。warmup=36 明け（≈2019.5）の二次モデルは「戦略が
  負けた初期」を主たる教師として学習したため、**戦略が効き始めた局面で露出を誤って削った**。
- OOS（2024-01〜）では gated +0.46 と ungated +0.51 がほぼ同等＝OOS では実害が小さい。害の大半は
  warmup 明け直後の 2019.5–2023 に集中。つまり「予測勝率→サイズ」に**安定した実エッジが無く**、
  非定常な教師に過剰反応した。

これはプロジェクト通底の知見「**長期データは非定常・旧データが誤誘導する**」（size 因子の崩壊、
value の局面依存と同型）の再演である。動的メタ重みは概念上妥当でも、**素朴な確率分類では一次の
非定常性を捌けず、かえって誤タイミングを生む**。
