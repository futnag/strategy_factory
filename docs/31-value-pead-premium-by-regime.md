# value/PEAD プレミアムのレジーム別推定（月次GKX行列）

**作成日**: 2026-06-23
**診断**: `examples/diag_value_pead_regime.py`（使い捨て・**K不変・判定なし**・オフライン）
**データ**: `data/phase4/X.parquet`（月次GKX設計行列・60因子・170,182行）＋ `y.parquet`（1か月フォワード超過リターン）。期間 2016-07〜2026-05。
**位置づけ**: docs/27 §8 の限界（**日次**キャッシュに book/market が無く value LS を再構築できなかった）を、**月次** GKX 行列で解消し、docs/27 のレジーム転換を**実際の戦略因子で定量裏づけ**する。

---

## 1. 結論

docs/27 が市場ボラ・トレンド・因子回転から特定した主要レジーム転換（**2020-03 COVID**・**2022-09 利上げ/value復権**）が、**value/PEAD プレミアムそのものの符号反転**として明確に現れた。とりわけ **value は エポックB（2018-10〜2020-03）で −0.72 と負**、**エポックD（2022-09〜）で +1.75 と急騰**。これは value+PEAD 戦略のサブ期間成績（−0.42→+0.53→+0.60）とも、メタゲート失敗の機構（docs/26）とも完全に整合する。

## 2. 方法

各月 t で、因子値の上位 quintile − 下位 quintile の y（1か月フォワード超過リターン）平均＝ロングショート・プレミアム。docs/27 の主要断層でエポック分割し年率 Sharpe を比較。y は既にユニバース平均に対する超過なので LS は純粋なファクター・プレミアム。

## 3. 結果：エポック別 年率 Sharpe

| 因子 | 全期間 | A 平穏ブル<br>16-07〜18-09 | B 後期→COVID<br>18-10〜20-03 | C コロナ後リフレ<br>20-04〜22-08 | D 利上げ/value復権<br>22-09〜 |

## 4. 解釈

1. **value は循環的に反転する因子**：A で弱く（+0.22）、**B で明確に負（−0.72＝COVID前後のグロース/質への逃避）**、C で復活（+0.55）、**D で爆発（+1.75＝利上げ・ZIRP終焉でのバリュー復権）**。docs/27 の「2020・2022-09 が分水嶺」を価格でなく**プレミアムで裏づけ**。
2. **PEAD はより頑健**（全エポックで正、Dで最大 +1.41）。ただし docs/03 の通り OOS では脆い局面があり、ロングティルト化で安定（docs/26 の一次モデル）。
3. **メタゲート失敗の決定的証拠**（docs/26 §4）：メタゲートの warmup=36か月は ~2019.5 に明け、**学習教師期間はちょうど value が −0.72 と負だったエポックB を中心に含む**。「value が負ける」関係を学習した二次モデルが、Dの +1.75 局面で露出を誤って削った＝逆位相の誤タイミング。本表はその機構を**プレミアムの符号反転として直接示す**。
4. **value+PEAD 戦略サブ期間（−0.42/+0.53/+0.60）との一致**：戦略はB相当で負け、C・Dで勝つ。戦略成績はこの因子プレミアムのレジーム依存でほぼ説明できる。

## 5. 注意・限界

- **事後（ex-post）診断**：エポック境界は docs/27 の事後転換点を使うため先読みを含む。これは「何が起きたか」の記述で、生シグナルではない（因果検知は docs/28、そこでも 2022 回転は遅行）。
- y は phase4 の正準ラベル（1Mフォワード・ユニバース超過・トータルリターン）。ユニバースは `universe.parquet`（流動性フィルタ）。
- 12Mローリングの正転月（2017-08/2018-06/2018-12/2020-01/2021-04/2025-06）はノイジーで、エポックSharpe ほどクリーンでない＝短期クロッシングは当てにしない。

## 6. 含意（一連の結論の統合）

docs/26（メタゲートFAIL）＋docs/27（レジーム多角分析）＋docs/28（因果検知の遅行）＋**本docs/31（value/PEADプレミアムの符号反転）**で一貫した像：
- value/PEAD の優劣は**レジームに強く依存**し、**~2020 と ~2022-09 で反転**。
- だが**独立な転換は10年で数回・因果検知は遅行**＝動的タイミングは学習困難。
- → 結論は一貫：**レジームは当てるより生き延びる**。value+PEAD は耐久コアとして保持し、タイミングで上積みしようとすると（メタゲート）かえって損なう。
