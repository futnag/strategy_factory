# 日足の因果的レジーム検知・仕様感応性レポート（PIT・オフライン）

**作成日**: 2026-06-23
**診断**: `examples/diag_causal_daily.py`（使い捨て・**K不変・判定なし**・オフライン・APIキー不要・先読みなし）
**対象**: 日次の価格系ファクター LS リターン（モメンタム/短期リバーサル/ロー・ボラ）＋等加重市場。2017-06〜2026-06（2,181営業日）。
**動機**: López de Prado の causal factor investing（specification error / collider bias / factor mirage）と、「**パフォーマンスのブレイクを待つのではなく、因果関係の structural break を監視せよ**」という考え方を、**日足で**実験する。

> 前提・制約：オフライン・キャッシュに book/market 値パネルが無いため value/PEAD の LS は再構築不可（docs/27 §8）。本診断は docs/27 M5 と同系の**価格系ファクター**で因果構造を扱う。価格由来の因子だけでは「因果的監視の先行性」は本質的に検証しきれない（§4・§5 参照）。

---

## 1. 結論（要旨）

- **仕様感応性は実在する**：因子間の関係は条件集合（何を control するか）で符号・強度が大きく動く（例：REV~LOWVOL 周辺 **+0.489** → 市場で条件付け **+0.101**）。「関係が有るか」は仕様依存＝**factor mirage の温床**を実データで確認。
- **collider bias は機構として実在**：合成データで `corr(u,v)=+0.001`（真に独立）が、共通結果で条件付けると **−0.919** に化ける。LdP の「colliderへの過剰な条件付けが偽の関係を生む」をそのまま再現。
- **ただし“mechanical に control / しない”の二択がそもそも誤り**：本データの価格系3組では市場で条件付けると相関は**減った**（市場は collider ではなく **confounder＝共有エクスポージャ**として作用）。**条件集合は因果図から選ぶべき**で、向きは真の因果役割に依存する——これが LdP の核心。
- **「因果構造ブレイクを監視すれば性能ブレイクに先行できる」は、価格由来の構造では成り立たない**：構造ブレイク（βmkt・偏相関の変化）は性能ブレイクに**ほぼ同時**（REV 28/28・LOWVOL 16/16 が同時、MOM のみ 5/14 が先行）。価格から作った“因果”系列は価格性能と同時に動くため、**リードタイムを生まない**。
- **含意**：LdP が約束する早期警戒の便益を得るには、**価格に外生な因果ドライバ**（マクロ・フロー・ファンダ）と**正しく仕様した因果図**が要る。価格系列だけの因果監視は docs/28（市場水準のオンライン検知）と同じ結論——**予測より防御**——に帰着する。

## 2. 方法

### Part A 仕様感応性 / collider bias（factor mirage の機構）
- **A1**：3因子（MOM/REV/LOWVOL）の LS リターン間で、**周辺相関** vs **偏相関**（市場 MKT で条件付け／MKT+市場ボラ MKTVOL で条件付け）を比較。偏相関は残差相関（線形回帰の残差同士の相関）で計算（≤窓のみ）。
- **A2-i**：合成・決定的 seed で `u ⟂ v` を生成し、共通結果 `C=u+v+ε` で条件付け → 偽相関の発生を定量化（機構の証明）。
- **A2-ii**：実データで「市場リターン＝多くの因子の共通結果」と仮定して条件付け、|相関| が増える組（collider 兆候）を検出。

### Part B 因果構造ブレイク vs パフォーマンスブレイク
- ローリング窓 **252営業日**で各因子に2系列を作る：
  - **構造系列**：(a) 市場への係数 **βmkt**（factor~MKT のローリング回帰係数）、(b) 他因子との**ローリング偏相関**（MKT・MKTVOL で条件付け）。
  - **パフォ系列**：ローリング平均 LS リターン。
- 各系列の**差分**に Page CUSUM（基準は ≤t 拡張窓・因果）を適用し警報時点を取得。
- **B3**：各パフォ警報の前後120営業日に構造警報があるか → **先行/同時/遅行/孤立**を集計。「先行」が多いほど構造監視に価値がある。

## 3. 主要結果

### 3.1 ファクター実測（年率）
| 因子 | mean | vol | Sharpe |
|---|--:|--:|--:|
| MOM（高モメンタム L/S） | +7.4% | 10.3% | +0.72 |
| REV（短期リバーサル） | −33.0% | 12.8% | −2.57 |
| LOWVOL（低ボラ L/S） | +13.9% | 17.6% | +0.79 |
| MKT（等加重市場） | +4.7% | 16.0% | +0.30 |

> REV の大きな負 Sharpe は「低リターン銘柄ロング」の素朴 L/S をコスト無視で日次評価したため（取引費用・反転の自己相殺で実運用とは別物）。本診断は**相関構造の素材**として使うだけで、戦略性能の主張ではない。

### 3.2 Part A — 条件付けで関係が動く
```
pair             周辺     |MKT   |MKT,VOL
MOM~REV        -0.080   -0.006     -0.010
MOM~LOWVOL     -0.223   -0.194     -0.196
REV~LOWVOL     +0.489   +0.101     +0.096
```
- **REV~LOWVOL** が +0.489→+0.101 と激減。これは**市場という共有エクスポージャ（confounder）**を除くと見かけの正相関の大半が消える、ということ。
- 合成 collider：`corr(u,v|C) = −0.919`（周辺は +0.001）。**条件付けの有無で結論が真逆**になり得る。
- 実データ3組では市場で条件付けて |相関| が**増えた組はゼロ**（collider 兆候なし）＝この価格系因子群で市場は collider ではなく confounder 寄り。

### 3.3 Part B — 構造ブレイクは性能ブレイクに先行しない
```
factor   パフォ警報数   先行   同時   遅行   孤立
MOM         14        5      7      2      0
REV         28        0     28      0      0
LOWVOL      16        0     16      0      0
```
- **REV・LOWVOL は完全に同時**。構造系列が価格から派生するため、性能と同位相で動く。
- **MOM だけ 5/14 が先行**——モメンタムは市場との関係（βmkt）が反転する局面（2018-12, 2020-01〜02 など）が性能悪化にやや先んじることがある、という弱い兆候。だが同時7・遅行2もあり、安定したリードではない。
- 警報数自体が20〜30と多い（ローリング系列の差分 CUSUM＝感応的）＝docs/28 と同じ**ホイップソー**の罠。

## 4. value+PEAD・メタゲートへの含意

- 本結果は docs/28（市場水準のオンライン因果検知）を**因子水準・日足**で裏づける：**価格由来の“因果”監視は性能監視より早く警告しない**。
- LdP の「因果 structural break を監視」が早期警戒として効くのは、**価格に外生なドライバ**（金利・ターム・VIX・海外フロー＝`data/phase4/macro.parquet`、ただし現状**月次**）で因果図を正しく組んだ場合に限られる。価格→価格の関係を見る限り、レジームは*当てる*より*生き延びる*（docs/26・27・28 と一致）。
- メタゲートが学習した月次の局面特徴も価格・自己状態由来だったため、本診断の「先行しない」と整合（docs/26 の FAIL を機構面から補強）。

## 5. 限界・次の手

> **訂正（docs/42 で判明）**：下記 (b) の「外生ドライバは月次」は誤り。`data/supplemental/macro_extended.parquet` 等に**日次**の VIX・USDJPY・SP500・日米金利・コモディティが揃っている（月次なのは `data/phase4/macro.parquet` の方だった）。この昇格パスは **docs/42 で実装・検証済み**（結論：外生ドライバ＋PCMCI+学習因果図でも因果効果ブレイクは性能ブレイクに先行しない＝本docs/41の結論を補強）。

- **データ制約が本質**：(a) value/PEAD LS はオフライン再構築不可（B/M パネル無し）。(b) ~~外生ドライバ（マクロ）は月次~~→**日次ドライバは存在**（docs/42）。価格系3因子だけでは「外生ドライバ→因子」の真の因果エッジを日足で引けない、という懸念は docs/42 で外生ドライバを入れて検証した。
- **正攻法（方向A・LdP プロトコル準拠）の昇格先**：
  1. 日次マクロ/フロー proxy を整備（VIX・USDJPY・先物ベーシス・海外フロー日次）。
  2. **PCMCI+（tigramite）** または **causal-learn** で「ドライバ→因子」の時系列因果図を学習（現状 venv 未導入。本診断は偏相関 CI を numpy/scipy で自前実装＝同型の軽量版）。
  3. 学習した**固定因果図**のもとで因果効果を推定し続け、その**効果系列**に CUSUM/BOCPD（＝方向B2）。価格性能でなく**外生ドライバ→因子の因果効果**の断層を見るので、初めて「先行」を検証できる。
- **collider の自動判定**：A2 は手動で市場を共通結果と仮定した。本来は因果図から collider/confounder を機械的に分類し、調整集合（adjustment set）を導く（do-calculus / backdoor 基準）。
- **セクター33業種展開（外部提案）は時期尚早**：方向A→Bが「外生ドライバで先行性あり」を示してからでないと、33セクター×個別変数選択で研究者自由度が爆発し DSR 規律を壊す。
