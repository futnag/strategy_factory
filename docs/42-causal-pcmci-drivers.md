# 外生ドライバ→因子の因果図学習(PCMCI+)と因果効果ブレイク監視レポート

**作成日**: 2026-06-23
**診断**: `examples/diag_causal_pcmci.py`（使い捨て・**K不変・判定なし**・オフライン・APIキー不要）
**対象**: 日次の価格系ファクター LS（MOM/REV/LOWVOL）＋**日次の外生ドライバ7種**（VIX変化・USDJPY・SP500・日10年・米10年・WTI・銅）。2017-06〜2026-06（1,964営業日・10変数）。
**手段**: PCMCI+（tigramite・ParCorr・tau_max=5・pc_alpha=0.01）で時系列因果図を学習 → 学習リンクの因果効果をローリング推定 → CUSUM で構造ブレイク監視。
**動機**: docs/41 の昇格パス（§5）。docs/41 は**価格由来**の構造（βmkt・偏相関）が性能ブレイクに先行しないことを示した。本診断は **価格に外生なドライバ**＋**学習した因果図**で、LdP が約束する「因果 structural break の早期監視」が日足で成立するかを検証する。

> **docs/41 §5 の訂正**：そこで「日次の外生ドライバが無い」としたのは誤り。`data/supplemental/macro_extended.parquet`（2,648営業日・21列）等に**日次**のVIX・USDJPY・SP500・日米金利・コモディティが揃っている。本診断はそれを使用した（制約は解消済み）。

## 1. 結論（要旨）

- **学習された因果図は経済的に妥当だが、リンクは弱い**：
  - **LOWVOL** ← SP500リターン（lag0 **−0.135**／lag1 **−0.113**）・USDJPY（lag0 −0.082）。米株リスクオン→低ボラ劣後、という整合的な向き。lag1 は US→JP の明確な先行リンク。
  - **REV** ← VIX変化（lag1 +0.075）・日10年変化（lag2/5）。リスク・金利が短期リバーサルを弱く先行駆動。
  - **MOM** ← **外生ドライバの親なし**（因子内ラグのみ）。日次モメンタム・プレミアムはマクロ駆動として検出されない。
  - MCI（リンク強度）は **0.07〜0.13** と総じて弱い。
- **外生ドライバを使っても、因果効果の構造ブレイクは性能ブレイクに“信頼できる先行”をしない**：
  - REV：性能警報19中 **先行2・同時16・遅行1**。LOWVOL：13中 **先行1・同時9・遅行1・孤立2**。
  - docs/41 の価格由来（REV 先行0/同時28・LOWVOL 先行0/同時16）から先行が僅増したが、**依然「同時」が支配**。早期警戒にはならない。
- **なぜ先行しないか**：(a) ドライバ→因子リンクが弱い→ローリング因果効果が**ノイズで揺れ**、CUSUM がホイップソー、(b) 因果効果系列と性能系列は**同じ市場イベント（特にCOVID 2020-03）に同位相で反応**、(c) 両系列とも警報20回前後と多く、±120日の同時一致は**一部機械的**（＝この設計の検出力は限定的）。
- **含意（LdP の正しい読み方）**：causal factor analysis の価値は**仕様を正すこと**（mirage回避・正しい調整集合で**プレミアムを不偏推定**）にあり、**レジームを当てるタイミング**にはない。LdP 自身も「因果監視が市場タイミングの先行を与える」とは言っていない。それはユーザーの希望的拡張であり、日足・因子水準のデータはそれを**支持しない**。docs/26–29 の通底結論——**予測より防御**——を、最も正攻法の手法でも追認した。

## 2. 方法

### Part 1 因果図学習（PCMCI+）
- 変数＝因子LS 3種（MOM/REV/LOWVOL・docs/41 と同じPIT構築）＋外生ドライバ7種（定常化：金利→差分・価格→対数リターン・VIX→変化）。
- 共通営業日で整合（因子LSの実現日 d にドライバの当日値・ラグを合わせる）→ 標準化 → `run_pcmciplus(tau_max=5, pc_alpha=0.01)`。
- 各因子の**親**（→因子の有意リンク）を MCI 降順で抽出。**lag≥1 のドライバ→因子**＝向きが明確な先行リンク（US/グローバルが JP を時差で先行）。

### Part 2–3 因果効果の構造ブレイク監視と先行性検定
- 各因子の最強ラグ付きドライバ親を主リンクに選び、**調整集合**（全ドライバ親を各自のラグでシフト）で因果効果をローリング回帰（窓252日）→ 主リンク係数 = 時変の因果効果。
- 因果効果の差分に Page CUSUM（≤t 拡張窓・因果）→ **構造ブレイク**。性能（ローリング平均LS）の差分にも CUSUM → **パフォーマンスブレイク**。
- 各性能警報の前後120営業日に構造警報があるか → **先行/同時/遅行/孤立**を集計。

## 3. 主要結果

### 3.1 学習された因果図（各因子の親・MCI降順）
```
[MOM]    REV(lag2 +0.092), LOWVOL(lag1 +0.075)            ← 外生ドライバ親なし
[REV]    LOWVOL(lag1 -0.076), VIX_chg(lag1 +0.075),
         REV(lag3 -0.073), JP10Y_chg(lag5 +0.073 / lag2 -0.064)
[LOWVOL] SP500_ret(lag0 -0.135), SP500_ret(lag1 -0.113),
         USDJPY_ret(lag0 -0.082)
```
- 素朴な仕様（docs/41 の「因子~市場のみ」）に対し、PCMCI+ は**外生ドライバのラグ付き親**を同定。調整集合が変わる＝**何を control するかで推定が変わる**（mirage の機構）。
- ただしリンク強度は弱く、日次の因子プレミアムの大半は外生マクロでは説明されない。

### 3.2 因果効果ブレイク vs パフォーマンスブレイク（先行性）
```
factor   主リンク              性能警報  先行  同時  遅行  孤立
REV      VIX_chg(L1)→REV         19      2    16    1    0
LOWVOL   SP500_ret(L1)→LOWVOL    13      1     9    1    2
MOM      （ドライバ親なし→対象外）
```
- **同時が支配**。外生ドライバの因果効果でも、構造ブレイクは性能ブレイクに先行しない。
- 先行（2・1件）は docs/41 の価格由来（0件）よりは多いが、警報多発下の±120日一致では**ノイズ範囲**。

## 4. value+PEAD・運用への含意

- 本結果は docs/27→28→29 の系列を**最も正攻法の手法で締める**：市場水準（docs/28）でも、価格由来の因子構造（docs/41）でも、**外生ドライバ＋学習因果図の因果効果**（本docs/42）でも、構造ブレイク監視は性能監視に対し**実用的な先行を与えない**。
- LdP の causal factor investing の正味の使いどころは：
  1. **仕様の是正**（collider/confounder を因果図から判別し、正しい調整集合で**ファクター・プレミアムを不偏推定**）＝docs/41 Part A の延長。
  2. レジームは**当てる対象でなく所与の環境**。因果検知の用途は **risk control**（暴落時のエクスポージャ縮小）＝docs/28 の結論を踏襲。
- セクター33業種展開（外部提案）は、日足・因子水準ですら外生ドライバの先行性が出ない以上、**さらに低S/Nのセクター×個別変数選択は研究者自由度の爆発**を招く。本系列の結論は「やらない」を支持する。

## 5. 限界・次の手

- **リンクが弱い**のは日次LSの低S/Nが主因。**月次・因子水準**でPCMCI+を回せばリンクは強まり得るが、(a) value/PEAD LS はオフライン再構築不可（B/Mパネル無し）で価格系に限られ、(b) docs/27 が月次・市場水準で既に「独立転換10年4回」の壁を示している。
- **検出力の限界**：両系列の警報多発で±120日一致が一部機械的。サロゲート（時系列ブートストラップ）で「先行」の有意性を測るのが筋だが、本診断（K不変・記述）では未実施。
- **PCMCI+ の前提**：ドライバの外生性を仮定（lag≥1 のドライバ→因子は時差で擁護可能）。contemporaneous リンクの向きは US→JP の時差解釈に依存。
- **正味の昇格先**：タイミングではなく **§4-1 の仕様是正**（因果調整でプレミアムを不偏推定し、value+PEAD の符号・大きさの安定性が改善するか）を一度きりで検証する方が、LdP の主張に忠実かつプロジェクトの DSR 規律と整合する。
