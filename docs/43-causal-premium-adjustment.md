# 因果調整によるファクター・プレミアム不偏推定と安定性レポート

**作成日**: 2026-06-23
**診断**: `examples/diag_causal_adjustment.py`（使い捨て・**K不変・判定なし**・オフライン・APIキー不要）
**対象**: phase4 の月次横断面設計行列（170,182行 × 60特性 / 119か月・2016-07〜2026-05）。target＝value（book_to_market・earnings_yield）と PEAD（sue_recent）。
**手段**: PC（causal-learn・Fisher-Z）で特性＋成果 y の因果図を学習 → backdoor 近似で調整集合を導出 → Fama-MacBeth プレミアムを **素朴(単変量)／因果調整／全部入り(59統制)** の3仕様で推定 → docs/27 の4エポックで符号・大きさの安定性を比較。
**動機**: docs/42 §4-1/§5。LdP の主張の**本筋**＝「レジームを当てる」ではなく「**仕様を正す**（collider/confounder を因果図で判別し、正しい調整集合でプレミアムを不偏推定）」を一度きり検証。value+PEAD の符号・大きさ安定性が因果調整で改善するか。

> **データ前提の訂正**：docs/27 §8・docs/41・docs/42 の「value/PEAD LS はオフライン再構築不可（B/M パネル無し）」は **日次 features キャッシュに限った話**。月次 phase4 GKX 行列には `book_to_market`・`earnings_yield`・`sue_recent/initial`・`forecast_revision` が揃っており、本診断はそれで value/PEAD プレミアムを直接推定した。

---

## 1. 結論（要旨）

- **仕様感応性（factor mirage）は実在し、大きい**：book_to_market のプレミアムは **素朴 +0.316（t=1.78）→ 全部入り +0.671（t=4.43）** と倍増し“高度に有意”に化ける。earnings_yield・sue_recent は **全部入りで符号反転**（+0.169→−0.037、+0.119→−0.029）。＝**何を統制するかで結論が変わる**。LdP の「**collider/mediator への過剰統制が偽の有意性・符号反転を生む**」を実データで確認。
- **因果図（PC）**：y に**直接**隣接するのは **book_to_market のみ**。earnings_yield・sue_recent は **B/M 経由**で y につながる（直接エッジなし）。＝**value（B/M）が“直接”の価格決定特性**で、益回り・PEAD の見かけのプレミアムは相当部分が B/M 経由（mediation）。
- **しかし因果調整は“エポック安定性”を改善しなかった**（LdP 予測は不成立）：
  - book_to_market：符号一致 **素朴 2/4 → 因果 0/4**（悪化）。
  - sue_recent：符号一致 **素朴 4/4 → 因果 2/4**（悪化）。
  - earnings_yield：素朴 2/4 ＝ 因果 2/4（不変）。
  - ＝因果調整しても**局面をまたぐ符号反転は消えない**。むしろ素朴推定の方が符号一貫なことすらある。
- **核心的含意**：**value+PEAD のレジーム依存は“仕様の錯覚（mirage）”ではなく、真の非定常性**。因果調整は推定の**衛生**（過剰統制の符号反転を避ける）を改善するが、**局面依存そのものは消せない**。これは docs/26–30 と同じ壁——非定常性は所与であり、*当てる*より*生き延びる*——に、最も正攻法（LdP の仕様是正）でも到達したことを意味する。

> **重要・§6 の精緻化で一部訂正**：本§1・§3 の v1 は (a) 調整集合に粗い「共通隣接」ヒューリスティクスを使い、(b) 全部入りが**期間非対称**（実質 C/D のみ）だった。§6 で **PC 厳密 backdoor＋クリーン統制（全エポック推定可）**に精緻化した結果、**「全部入りで B/M が +0.671/t=4.43 に倍増」は期間人工物**（クリーン統制では +0.298＝素朴並み）と判明し、**「因果調整が安定性を悪化（0/4）」も v1 の誤った調整集合の産物**（厳密 backdoor では 2/4＝素朴と同等）と判明した。**核心結論（真の非定常性・因果調整で消えない）は精緻化後も不変**で、むしろ「正しい因果調整は良性（≈素朴）／過剰統制は符号反転」と明確化された。詳細は §6。

## 2. 方法

- **横断面標準化**：各月内でランク→z（外れ値は構造的に除去・先読みなし）。y は生のフォワードリターン（プレミアムをリターン単位で出す）。
- **因果探索**：ファクター分類で代表15特性（value/PEAD/trend/size/liquidity/quality/risk/growth 各代表）＋y を選定（**outcome を覗いた選択ではない**＝in-sample 選択回避）。PC（Fisher-Z・alpha=0.01・4万行サブサンプル）で CPDAG を学習。
- **調整集合（backdoor 近似）**：target と y の**両方に隣接**する変数＝交絡候補のみを統制。target のみに隣接（＝target の子＝collider/mediator 候補）は**統制しない**。
- **Fama-MacBeth**：月次横断面 OLS の傾きを平均、Newey-West（lag=6）t 値。3仕様＝素朴(単変量)／因果調整／全部入り(59統制)。
- **安定性**：docs/27 の4エポック別にプレミアム平均、符号一致数と |変動係数(CV)| を比較。

## 3. 主要結果

### 3.1 因果図と調整集合（PC）

```
book_to_market : y と直接隣接   調整集合={beta}
earnings_yield : y と間接/無    調整集合={book_to_market}
sue_recent     : y と間接/無    調整集合={book_to_market, beta}
```

### 3.2 全期間プレミアム（×100・NW-t）— 仕様感応性
| target | 素朴(単変量) | 因果調整 | 全部入り(59) | mirage幅 |
|---|--:|--:|--:|--:|
| book_to_market | +0.316 (t1.78) | +0.305 (t1.63) | **+0.671 (t4.43)** | 0.366 |
| earnings_yield | +0.169 (t1.58) | +0.034 (t0.50) | −0.037 (t−0.53) | 0.135 |
| sue_recent | +0.119 (t1.94) | +0.057 (t1.29) | −0.029 (t−0.80) | 0.090 |

- 全部入りは B/M を**倍に膨らませ**“有意”化（mirage）。益回り・PEAD は**符号反転**。＝過剰統制の害が定量的に出た。

- **因果調整しても B/M は A/B（2016–2020）で負・C/D（2020以降）で正**の反転が残る。これは docs/27 の「value は ~2020 と ~2022-09 で本物の構造転換」と完全に整合＝**非定常は実在**。

## 4. value+PEAD・運用への含意

- LdP の causal factor investing の**正味の効用は推定衛生**：全部入り（kitchen-sink）の偽有意・符号反転を避け、**簡潔な因果調整集合**で推定すること。本診断は「全部入りは危険、因果調整は健全」を支持する。
- だが**レジーム依存を消す魔法ではない**：因果調整後も value/PEAD の符号は局面で反転。＝docs/26（メタゲートFAIL）・docs/27（10年で構造転換4回）・docs/28-30（因果検知は性能に先行せず）と**同一の結論**。value+PEAD の成否を決める非定常は**仕様の問題ではなく環境の問題**。
- 実務：(a) プレミアム推定は**因果調整（簡潔）**で行い全部入りを避ける、(b) レジームは**当てず防御**（暴落時エクスポージャ縮小＝docs/28）、(c) value+PEAD は**長期保有で局面をまたぐ**設計（タイミングに賭けない）。

## 5. 限界・次の手

- **全部入りの早期欠測**：60特性が揃う銘柄が早期に少なく、kitchen-sink は C/D のみ。仕様比較の一部が期間非対称。char サブセット（揃う特性のみ）での再推定が筋。
- **backdoor 近似の粗さ**：CPDAG の「target と y の共通隣接」を交絡候補とする簡易基準。本来は辺を向き付けて proper backdoor 集合を導く（PC のオリエンテーション＋do-calculus）。PC は探索変数集合・alpha に感応。
- **PEAD の取り扱い**：sue は四半期イベントだが phase4 は月次断面。イベント時刻アンカー（提出日）での PEAD 専用パネルなら結果が変わり得る（KB の PIT 規律）。
- **正味の前進**：因果調整は「推定を歪めない」ためのツールとして採用価値あり。一方「レジーム依存を推定で消す」路線はここで打ち止め。次に value+PEAD を進めるなら、**因果調整済みプレミアムを所与**として、タイミングではなく**保有期間・分散・リスク管理**で非定常を吸収する設計に注力するのが、本シリーズ（docs/26–31）の一貫した示唆。

## 6. 精緻化（追補）— PC 厳密 backdoor＋クリーン統制

**診断**: `examples/diag_causal_adjustment2.py`（§5 の2点を潰す）。

### 6.1 何を直したか
- **精緻化1（早期欠測）**：v1 の「全部入り60」は `seasonality`(45%NaN)・`mom_36m_reversal`(26%)・`rd_intensity`(26%) 等が**横断面分散ゼロ/ルックバック不足**で NaN 化し、全60が揃う月が **2021-07 以降のみ**だった（＝epoch C/D だけ）。**NaN≤3% のクリーン42特性**で統制すると **A/B 含む全エポックで推定可能**になり、仕様比較が対称化。
- **精緻化2（backdoor の粗さ）**：v1 の「target と y の共通隣接」を、**PC のオリエンテーション（Meek 規則）で同定した厳密な親（Z→target）**に置換。CPDAG は **有向44・無向3**でほぼ向き付け可能だった（高共線でも v-structure が十分あった）。

### 6.2 判明した v1 の誤り
- **earnings_yield / sue_recent の調整で book_to_market を統制していたのは誤り**。PC は **earnings_yield→book_to_market**・**sue_recent→book_to_market** と向き付け、**B/M は両者の“子”（collider/媒介）**。子を統制するのは LdP が戒める**過剰統制そのもの**で、v1 の「因果調整で EY が +0.034 に潰れる」は人工物だった。
- 厳密 backdoor（親のみ）では：book_to_market の親=10個（earnings_yield・sue・mom_1m_reversal・amihud・roe・gross_prof・beta・ivol・asset_growth・sales_growth）、earnings_yield の親=4個、sue_recent の親=6個。

### 6.3 精緻化後のプレミアム（×100・NW-t）
| target | 素朴 | **厳密因果backdoor** | クリーン統制(41・過剰) |
|---|--:|--:|--:|
| book_to_market | +0.316 (t1.78) | **+0.375 (t1.95)** | +0.298 (t1.63) |
| earnings_yield | +0.169 (t1.58) | **+0.161 (t1.46)** | −0.085 (t−1.27) |
| sue_recent | +0.119 (t1.94) | **+0.081 (t1.67)** | −0.179 (t−0.94) |

- **厳密因果 ≈ 素朴**（B/M +0.375 vs +0.316／EY +0.161 vs +0.169／SUE +0.081 vs +0.119）。＝**正しい因果調整は良性**（プレミアムを保持し、歪めも膨らませもしない）。
- **過剰統制（クリーン41＝子/媒介を巻き込む）は EY・SUE を符号反転**（+0.169→−0.085、+0.119→−0.179）。＝**LdP の「過剰統制の害」は成立**。
- v1 の「全部入りで B/M が +0.671/t=4.43」は**消えた**（クリーン統制 +0.298）。＝あの“倍増・高度有意”は**期間非対称の人工物**で、過剰統制インフレではなかった（v1 を訂正）。

### 6.4 精緻化後のエポック安定性（×100・符号一致）
```
[book_to_market]   A平穏  B→COV  Cリフレ  D復権   一致  CV
  素朴            +0.117 -0.366 +0.337 +0.694  2/4  1.96
  厳密因果        +0.287 -0.613 +0.623 +0.644  2/4  2.17   ← v1の0/4は誤り
  クリーン統制(過剰) -0.088 -0.583 +0.626 +0.643  0/4  3.45
[sue_recent]
  素朴            +0.056 +0.007 +0.030 +0.257  4/4  1.14
  厳密因果        +0.019 -0.007 +0.053 +0.156  2/4  1.12
```
- **厳密因果の符号一致は素朴と同等**（B/M 2/4＝2/4）。v1 の「因果で 0/4 に悪化」は誤った調整集合の産物で、**精緻化で否定**。
- だが **B/M は厳密因果でも A/B 負・C/D 正の反転が残る**（+0.287/−0.613/+0.623/+0.644）。＝**核心結論は不変：value のレジーム依存は真の非定常性**で、正しい因果調整でも消えない。

### 6.5 精緻化の結論
1. **正しい因果調整（厳密 backdoor・簡潔）は良性**＝素朴とほぼ同じプレミアム・同等の（不）安定性。歪めない。
2. **過剰統制（子/媒介/colliderを巻き込む）は符号反転を生む**＝LdP の警告は成立。**kitchen-sink を避け、backdoor 親のみで調整せよ**が実務指針。
3. **レジーム依存は仕様で消せない**（厳密因果でも B/M は局面反転）＝docs/26–31 通底の「予測より防御」を、精緻化済みの最も厳密な手法でも追認。
4. **副次：PC は高共線な因子でも十分向き付け可能**（有向44/無向3）。ただし backdoor 同定は探索変数集合・alpha に依存し、ここでの親集合は「代表15因子」の枠内での話。
