# 48 — ストップ高リバーサル 事前登録（候補：日次イベント＝レジストリ外の新軸／`UL`フラグを"コスト"から"シグナル"へ）

**作成日**: 2026-06-28
**位置づけ**: docs/03 §6.20 の「9候補独立α 全棄却」＋テキスト(#1)・条件付きSDF(#2) もFAIL を受けた次の一手。
9連敗＋テキスト＋SDF はいずれも「価格・ファンダ・需給・テキストの**横断再正規化**（月次リバランス）」だった。
`UL`/`LL`（ストップ高/安ヒットフラグ）は `frictions.py` で**執行コスト（張り付き）としてのみ**使われ、
**シグナルとしては 742 試行のどの scope にも入っていない**＝未踏の**日次イベント軸**。

記述スキャン（2026-06-28・PIT/コスト/DSR なしのスコープ確認）で、ストップ高(UL==1)の**翌営業日寄り→+5/+10日**が
**一貫して負**（h5 中央値 −3.81%・勝率37%・**10/11年で負**・無条件 +0.25%/勝率50%）であることを確認。
9連敗の共通病（「2016-23で機能→2023-26で死」）と異なり**直近regimeでも反落が持続**する点が事前の手掛かり。

## 0. なぜストップ高イベントか（失敗型の構造的回避）

| 9連敗の失敗型 | ストップ高イベントでの構造的回避 |
|---|---|
| momentum代理 | トリガは「制限値幅に達した」という**離散イベント**＝価格水準の単調変換でない |
| value共変 | 行動イベント（注意誘発の買い）であって value/PBR改革regimeと無関係 |
| 既試redux | `UL` シグナルは全 scope に未登録＝新データ軸 |
| 直近regime共変／OOS負 | 記述スキャンで**10/11年負・直近(2025)も −1.4%**＝直近死の事前反証 |
| de-risk | 指数タイミングでなく**横断 L/S（イベント名ショート × 流動EWロング）でαを測る** |

**ただし最大の現実リスク＝借株（ショート側）**。ストップ高銘柄は最も借株困難（高逆日歩・増担保・貸借停止）で、
紙上のリバーサルが借株コストと「そもそも空売れない」で消える公算が高い。本登録はそれを**正面から課す**
（保守的貸株コスト＋値幅ロック）設計とし、借株不要の実用形（H3 除外オーバーレイ）を併走させる。

## 1. 実現可能性（実測済み・2026-06-28）

- **イベント実在**: wide `upper_limit`/`lower_limit`（=`UL`/`LL`、**0/1 フラグ**）で `UL==1` ＝**25,852件**
  （2016-06〜2026-06・約10.6件/日）、`LL==1` ＝6,313件（約2.6件/日）。物理的に妥当な水準。
- **執行現実性の部品が既存**: `equities/frictions.py:limit_lock_flags(close,high,low,UL,LL,vol)` が
  引け張り付き（`UL==1 かつ close>=high`＝買い越し不能／`LL==1 かつ close<=low`＝売り越し不能・出来高0は両側不能）を
  bool パネルで返す。エンジンの `no_buy/no_sell`・`short_borrow_bps`・`adv` 容量にそのまま接続。
- **記述スキャン結果（翌寄エントリー・コスト/DSRなし＝スコープ確認のみ）**:

  | h5（翌寄→+5日寄） | n | 平均 | 中央値 | 勝率 |
  |---|---|---|---|---|
  | 無条件 | 9.6M | +0.25% | 0.00% | 49.7% |
  | ストップ高の翌日 | 25,596 | **−1.37%** | **−3.81%** | **37.1%** |

  年次 h5 平均は 2016〜2025 の **10年で負**（2021 −2.5% / 2022 −2.8% / 2023 −1.8% / 2025 −1.4%、2026途中のみ +0.4%）。
  流動上位でも反落（中央値 −4.8%）＝純粋な超小型アーティファクトでない。ストップ安側はノイズ（中央値0%・符号不安定）。
- **データバグ修正**: `docs/24` は `UL/LL` を「制限値幅 上/下限（価格）」と誤記していた（実体は0/1フラグ）。
  §1/§3.2/§5-10 を修正済（`close>=UL` 等の価格比較は破綻する旨を明記）。

## 2. 事前登録：仮説と設計（**走らせる前に固定**）

### 2.1 主仮説（falsifiable）
**H1（ストップ高リバーサル）**: 当日ストップ高（`UL==1`）を記録した銘柄は、翌営業日以降アンダーパフォームする。
**イベント名ショート × 流動ユニバースEWロング**のドルニュートラル日次戦略が、**保守的貸株コスト（年率300bps）＋
値幅ロック（no_buy/no_sell）＋片道30bps** を課しても、大域デフレートDSR で **DSR ≥ 0.95** を満たす。

**H2（局在＝裁定の限界）**: 効果は**低流動性帯で増大**する（注意誘発の過剰反応は裁定が薄い銘柄で大きい）。
低流動帯セルが全銘柄セルと**同等以上**の純エッジを持つ。大型でのみ効くなら行動仮説に疑問を付す。

**H3（実用形・診断＝K外）**: 直近 `EXCL_WIN=20` 営業日以内にストップ高を付けた銘柄を**ロング簿から除外**すると、
素のロング簿に対し **Sharpe 改善・maxDD 縮小**（除外−素 のスプレッドSharpe>0）。**借株不要**＝最も現実的な収穫形。

### 2.2 経済的根拠
ストップ高＝**注意誘発（attention-induced）＋宝くじ需要（lottery demand）＋個人の追随（herding）**による一過性の
過剰反応。板の買い超過は翌日以降に冷め、**裁定の限界**（借株困難・小型・カバー希薄）ゆえ緩やかに反転する。
反対側＝叙述やニュースの一次情報で動かず、過熱を供給する冷静な参加者。**価格水準の単調変換では作れない独立イベント**で、
9連敗の各失敗型（特に momentum代理・value共変）を構造的に避ける。

### 2.3 データ・PIT規律
- **トリガ**: `UL==1`（引け時点で既知）。decision 日 t、`execution_lag=1`（**翌足執行**＝観測した足で建てない）。
- **保有窓**: 名 c が日 d にストップ高 → t∈[d, d+HOLD−1] の各日のウェイトに在席（ローリング）。実現は t+1→t+2 の連鎖。
- **ユニバース（PIT・生存者バイアス排除）**: 普通株（`filter_common_stocks`）。各 t で「取引中（turnover>0）かつ
  trailing 252日に≥120日約定」を eligible。流動ヘッジは trailing 中央値売買代金で**上位300**、低流動帯は**[300,1500)**。
- **フリクション**: `limit_lock_flags` の no_buy/no_sell（執行バー t+1 で評価）。貸株 `short_borrow_bps=300`（年率・
  ショート想定元本に按分）。容量 `adv`（=turnover, participation=0.1）。コスト片道30bps。

### 2.4 シグナル構築（**3セル＝K=3**・走らせる前に固定）
| name | ユニバース（ショート対象） | HOLD | 目的 |
|---|---|---|---|
| `lu_rev_h5` | 全 eligible 普通株 | 5 | H1 主判定 |
| `lu_rev_h10` | 全 eligible 普通株 | 10 | 保有窓の頑健性 |
| `lu_rev_h5_illiq` | 低流動帯 [300,1500) | 5 | H2 局在 |

各セル：ショート＝当該ユニバースの「窓内ストップ高名」EW（Σ=−1）、ロング＝上位300流動名（イベント名を除く）EW（Σ=+1）
＝ドルニュートラル。イベント0件の日は現金。`PrecomputedWeights` でエンジンへ。

### 2.5 judge_grid 連結（既存機構）
`scope="limit_reversal"`、`execution_lag=1`、`costs_bps=30`、`short_borrow_bps=300`、`no_buy/no_sell`、`adv`、
永続レジストリで大域デフレートDSR（K=3）。実装＝`examples/research_limit_reversal.py`、レポート＝`data/reports/limit_reversal.html`。

### 2.6 合格基準（事前固定）
1. **DSR ≥ 0.95**（貸株300bps＋値幅ロック＋30bps後・多重検定デフレート後）。
2. **サブ期間符号一貫**（3分割で正・直近のみ＝④型は不採用）。
3. **H2 局在**：低流動帯セル ≥ 全銘柄セル（純エッジ）。
4. **借株感応で損益分岐が現実的**：貸株 sweep {115,300,500,1000}bps と片道コスト sweep で、
   損益分岐の貸株率が**実勢の逆日歩水準より十分高い**こと（＝薄い前提でしか黒字化しないなら不採用）。

### 2.7 既知の限界＝借株データ（重要・正直化）
真の**逆日歩・品貸料・貸借可否（増担保/貸借停止）**のデータを保有しない。`short_borrow_bps=300` は保守仮定にすぎず、
ロックされた名は実際には**空売り不可**な日が多い → **ショート版（H1/H2）は楽観的になりうる**。だからこそ
**H3 除外オーバーレイ（借株不要・ロング簿のみ）**を併走させ、実用価値はそちらで測る。本格運用には
**JSF（日本証券金融）の貸借残・逆日歩**の統合が必要（応答で提案したオルタナデータの最優先候補の一つ）。

## 5. 結果（判定済み・2026-06-28）

**判定＝❌ FAIL**（scope=`limit_reversal`, K=3, レジストリ登録済）。最良 `lu_rev_h5_illiq` でも **DSR=0.26**（<0.95）。
全3セルが net 負（lu_rev_h5 −0.12 / h10 −0.31 / illiq −0.10）、PBO(CSCV)=**0.94**（高・過学習）。UL==1=21,760件（普通株・8.9/日）。

### 機構（＝最重要・"なぜ"が綺麗に割れた）
- **gross は強正**：lu_rev_h5 **gross SR +1.08**（h10 +0.64 / illiq +0.79）＝ストップ高銘柄の相対アンダーパフォーム
  （リバーサル）は**実在**。記述スキャン（h5 中央値 −3.8%）と整合。**シグナル自体は本物**。
- **死因＝取引コスト**（借株でない）。コスト感応（貸株300bps固定）: 0bps **+0.98** / 15bps +0.43 / **30bps −0.12** /
  50bps −0.85 / 100bps −2.66 ＝**損益分岐≈片道25bps**。ストップ高銘柄の実勢スプレッドはこれより広く、
  楽観的30bps床ですでに負。回転0.42/日×ワイドスプレッドが gross を食い切る。
- **借株は二次的**：貸株感応 0bps −0.02 / 115bps −0.06 / 300bps −0.12 / 1000bps −0.36 ＝コスト30bps時点で既に負。
- **値幅ロックの現実**：no_buy/no_sell で **1,707件の執行がブロック**（「ロック中は空売れない/買い戻せない」を定量化）。
- **容量 ¥0.2–0.4百万**＝極小・非スケール（イベント名の |w| が薄く流動性が低い）。
- **by-year net は符号不安定**（2022 +2.15 / 2024 +0.92 vs 2017 −1.23 / 2018 −1.14 / 2026 −1.42）＝コストが
  gross の一貫性（10/11年負＝robust だった）を破壊。

### H3 除外オーバーレイ（借株不要・診断）
直近20日ストップ高をロング簿から除外：素 SR **+0.59**→除外 **+0.61**、maxDD −30.3%→−30.4%、スプレッド(除外−素)
SR +0.37・**+2.0bps/月**。＝統計的に正だが**経済的に無視可能**（月平均除外4.7銘柄）。実装非推奨。

### 結論
ストップ高リバーサルは **gross 実在・net 非トレーダブル**（取引コスト/回転・値幅ロック・極小容量で死亡）。借株不要の
除外オーバーレイも +2bps/月で無価値。＝**「紙上αがスプレッドで死ぬ」型の実証**（micro-cap ブリーフィング §3.2）。
独立イベント軸だが認定未達＝プロジェクト中心知見「**valueのみ控えめに耐久・独立な耐久エッジ無し**」を再確認（10例目の棄却）。
失敗型は新種＝**「gross有・cost死・非スケール」**（従来の直近共変/OOS負/符号逆/momentum代理/de-risk/古データ減衰 と別型）。

### 再評価の条件（将来・低EV）
gross が本物なので、トレーダブル化には①超低コスト執行（自己板内・寄り回避）②回転低減（ただし h10 は gross/SR も低下）
③**JSF 逆日歩/貸借残の統合で空売り可否・実コストを実値化**（docs/48 §2.7）。いずれも EV 低。打ち止め推奨。
