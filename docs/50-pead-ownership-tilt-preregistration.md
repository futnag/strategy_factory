# 50 — 所有構造で条件付けたPEAD（value+PEAD 旗艦の精緻化）事前登録

**作成日**: 2026-06-28
**前提**: Jinushi(2023) 再現（`examples/research_pead_ownership.py`）／docs/44（value-pead設計）／docs/03 §6.27（旗艦は
scope内 DSR≥0.95 だが**大域デフレートでは 0.21–0.78＝未認定**）。
**実装**: `examples/research_pead_ownership_tilt.py`、所有パネル `data/edinet/ownership_categories.parquet`。

## 0. 動機（論文 → 旗艦の弱点 → てこ）
Jinushi(2023)＝PEAD は**低外国人/高個人**銘柄に集中。本リポの再現でも全サンプル代理で **小型/個人 +1.36%(t3.5)
vs 大型/外国人 +0.02%(t0.04)**、実所有でも方向一致。これは旗艦の弱点を説明する：value+PEAD の土俵＝**流動 top300
＝高外国人の大型株中心＝PEAD が裁定消滅している領域**。よって **PEAD を foreign% で条件付け（低外国人へ傾ける）**
＝最も理論的に妥当な精緻化。本事前登録はこれを**新規スコープとして公正に一回判定**する（in-sample 改善は無効）。

## 1. 仮説（falsifiable・走らせる前に固定）
- **H1（条件付けの効果）**: PEAD L/S を**低外国人サブユニバースに限定/傾斜**すると、全ユニバースの素 PEAD より
  **純SR・大域デフレートDSR が高い**。高個人サブユニバースでも同様。
- **H2（size 超過＝最重要ガード）**: 低外国人条件付けが**低ADV（size）条件付けを上回る**＝foreign% は size の代理を超えて
  PEAD を予測する。**lowF ≈ lowADV なら却下**（size は PIT で FAIL 済＝DSR0.82→0.35。新規性なし）。
- **H3（旗艦反映）**: 条件付き PEAD 脚は素 PEAD 脚より望ましい（純SR/DSR・容量・サブ期間安定）。

## 2. データ・ユニバース（PIT）
- **ユニバース**: 流動 top-300 普通株 ∩ **EDINET-DB 所有データ取得済み（FY2014+ のうち実取得 ~160銘柄）**。
  ⚠ レート制限で top-300 の中流動帯（~98銘柄）が欠落＝**~160/300 のバーベル的被覆**（限界として明記）。
- **PEADシグナル**: `feature_store.load_feature("sue_recent")`＝本決算の実績−会社予想EPS の surprise yield、月末 PIT。
  セクター中立 z 化。`forecast_revision` を頑健性で併用可。
- **所有分類**: 各銘柄の **median foreign%／median individual%**（持続タイプ＝期間中央値・先読みなし）。median 2分割。
- **size 対照**: trailing ADV の median 2分割（H2 の size 超過検定用）。

## 3. 戦略格子（K＝事前固定）
| name | 内容 |
|---|---|
| `pead_all` | 全ユニバースの素 PEAD L/S（基準） |
| `pead_lowF` | **低外国人**サブのみで PEAD L/S（H1） |
| `pead_highF` | 高外国人サブのみ（対照＝弱いはず） |
| `pead_highIndiv` | 高個人サブのみ（H1） |
| `pead_lowADV` | **低ADV(size)** サブのみ（H2 の size 対照） |
| `pead_xF` | 連続傾斜＝sue × (1−foreign_rank)（低外国人ほど加重） |

判定: `scope="pead_ownership_tilt"`、`judge_grid`（永続レジストリで**大域デフレートDSR**）、月末リバランス、
コスト15bps（流動 top300＝楽観床）、`adv` 容量、値幅ロック `no_buy/no_sell`、execution_lag、T+1始値で頑健性。

## 4. 合格基準（事前固定）
1. **DSR ≥ 0.95**（多重検定デフレート後）。
2. **H1**: `pead_lowF`（and/or `pead_highIndiv`, `pead_xF`）の純SR が `pead_all` を明確に上回る。
3. **H2（必須）**: `pead_lowF` > `pead_lowADV`（foreign が size を超える）。下回れば「size の代理」＝却下。
4. **サブ期間符号一貫**（直近のみ＝④型は不採用）。
5. **容量・コスト現実性**（低外国人へ寄ると小型化＝スプレッド/容量悪化を net で確認）。

## 5. 失敗型ガード（この repo の歴史が示す逆風を事前に直視）
| 逆風（実績） | 本設計での扱い |
|---|---|
| **ゲーティング全敗**（meta-gate DSR 0.07–0.31） | 条件付けも“ゲート”。基準②で**素 PEAD 超過**を必須化＝ゲートで損なら不採用 |
| **size が PIT で FAIL**（0.82→0.35） | 基準③で **foreign-beyond-size** を必須化（lowADV 対照） |
| **容量・コストの壁**（limit-reversal/microcap を殺した） | net・容量を判定に内包。低外国人＝小型寄りの不利を露出 |
| **旗艦自体が大域未認定** | これは“認定”でなく“素PEAD比の改善”の有無を測る研究。過剰主張しない |

## 6. 正直な事前予想
機構（gross）は本物（再現済）。だが (a) 低外国人≒小型→容量/コスト、(b) ゲーティング全敗、(c) ~160銘柄・2016+ の
検出力 を踏まえると、**net/大域DSR では FAIL の可能性が高い**。その場合も「foreign% は gross では効くが tradeable な
旗艦改善には至らない（容量/ size 代理）」を厳密に記録＝11例目の知見化。PASS なら旗艦 PEAD 脚を低外国人傾斜へ更新。

## 7. 結果（判定済み・2026-06-28）

**判定＝❌ FAIL**（scope=`pead_ownership_tilt`, K=6, 登録済）。最良 `pead_highIndiv` でも **DSR=0.57**（<0.95）、PBO(CSCV)=0.80。
ユニバース=160銘柄（top300の中流動帯はレート制限で欠落）。lowF∩lowADV/lowF=0.72。

| strategy | net年率SR | DSR | 容量 | T+1 |
|---|--:|--:|--:|--:|
| pead_highIndiv | +0.27 | 0.57 | ¥205万 | +0.22 |
| pead_lowF | +0.22 | 0.51 | ¥397万 | +0.17 |
| pead_lowADV(size対照) | +0.21 | 0.51 | ¥411万 | **−0.16** |
| pead_xF | +0.15 | 0.42 | ¥616万 | +0.11 |
| pead_all(基準) | +0.05 | 0.31 | ¥616万 | +0.21 |
| pead_highF(対照) | −0.17 | 0.11 | ¥205万 | +0.13 |

### 解釈（何が言えたか）
- **H1 ＝強く支持（方向・大きさとも）**: 低外国人/高個人へ条件付けると net SR が **+0.05→+0.22〜+0.27（約4〜5倍）**、
  高外国人対照は **−0.17（負）**。＝**論文どおり PEAD は低外国人/高個人に集中**。これは**旗艦のPEAD脚が弱い理由を説明**する
  （流動top300＝高外国人で希釈）。
- **H2 ＝不支持（最重要の負の所見）**: `pead_lowF(+0.22) ≈ pead_lowADV(+0.21)`、重なり72%。**foreign% は SR 次元では size を
  ほぼ超えない＝条件付けの主因は size**（size は PIT で FAIL 済＝この経路は認定に乗らない）。
  - ただし**例外的な foreign-beyond-size の痕跡**：①`pead_highIndiv(+0.27)` が size対照(+0.21)を上回る、
    ②**T+1 執行で lowF(+0.17) は生存するが lowADV(−0.16) は崩壊**＝小型 size 版は寄り執行で死ぬが、低外国人版は耐える
    （所有条件付けの方が執行頑健）。
- **認定は未達**: 最良 DSR 0.57・PBO 0.80・容量¥2〜4百万（小型化の容量壁）。サブ期間は lowF が前後2020で +0.20/+0.23 と
  一貫（highIndiv は初期負）。

### 結論
**経済的には「効く」＝論文の精緻化は本物**（低外国人/高個人傾斜で PEAD 脚の net SR が4〜5倍、高外国人は負）。
**だが統計的には認定未達**（DSR0.57）＋**主因は size**（foreign の独立寄与は SR では小・T+1頑健性では有）＋**容量制約**。
＝旗艦自体と同じ「**強い経済候補・未認定**」カテゴリの**精緻化**であって、認定済みアップグレードではない。

### 推奨（過剰主張しない反映）
1. **旗艦 PEAD 脚を「高個人/低外国人 傾斜」へ更新する価値はある**（経済的動機・gross/net で素PEADを明確に上回る・
   T+1頑健）。ただし**未認定・size寄り・容量小**を明記して採用（旗艦の他スリーブと同格の扱い）。
2. **認定へ近づける次手**: (a) top-300 の中流動帯 ~98銘柄の所有を補完取得しユニバースを厚く、(b) **individual% の
   size 超過分**を残差化で分離（highIndiv が size を上回った点を精査）、(c) value 脚にも所有条件（持合い/低外国人=
   バリュートラップ）を当てるか検討。いずれも EV は中（size 代理リスク）。
- レポート: `data/reports/pead_ownership_tilt.html` / 実装: `examples/research_pead_ownership_tilt.py`・`examples/research_pead_ownership.py`

### 7.1 ユニバース増補後の再判定（263銘柄・2026-06-28）
所有取得をレート制限の欠落分まで補完（top-300 to-fetch の **238/243**・所有パネル263コード）し再走。**§7 を上書きする最新結果**。

| strategy (263名) | net年率SR | DSR | 容量 | T+1 |
|---|--:|--:|--:|--:|
| pead_lowF | +0.19 | **0.36** | ¥740万 | +0.02 |
| pead_lowADV(size対照) | +0.11 | 0.27 | ¥22万 | −0.16 |
| pead_highIndiv | +0.03 | 0.20 | ¥616万 | −0.22 |
| pead_xF | −0.04 | 0.14 | ¥1143万 | −0.21 |
| pead_all(基準) | −0.22 | 0.04 | ¥1437万 | −0.29 |
| pead_highF(対照) | −0.45 | 0.01 | ¥616万 | −0.46 |

**判定＝❌ FAIL**（最良 pead_lowF DSR=0.36<0.95）。だが **PBO 0.80→0.47**（過学習が大幅減）。増補で所見が鋭くなった：
- **H1 ＝より明確**: 素 PEAD は流動top300で **負(−0.22)**、高外国人 **−0.45**。低外国人限定で **+0.19 に反転**＝
  **高外国人がPEAD脚を負に引っ張っている**（drift が反転している領域）。
- **H2 ＝今度は支持（160名では曖昧だった foreign-beyond-size が分離）**: `pead_lowF(+0.19) > pead_lowADV(+0.11)`、
  かつ**容量 ¥740万 >> ¥22万**（size版は極小illiquidに集中）、**T+1 で lowF だけ生存(+0.02 vs size −0.16)**。
  ＝**foreign% は size の代理を超え、しかも遥かに容量大・執行頑健**。＝「size の言い換え」懸念は厚いユニバースで否定。
- **highIndiv は崩壊**（+0.27→+0.03）＝160名版のhighIndivは小標本ノイズ。**頑健な軸は外国人**であって個人ではない。
- だが**認定は依然未達**（DSR0.36・SR+0.19・IS−0.26/OOS+1.23＝直近集中・サブ期間 +0.14/−0.07/+0.46）。

**結論（更新）**: 精緻化の正味＝**「PEAD脚から高外国人を除外/縮小」**（負ドリフトを除く）。これは **foreign 固有・容量大(¥740万)・
T+1頑健**＝size代理でも非スケールでもない、**経済的に妥当な旗艦改善**。ただし **DSR0.36＝未認定・直近集中**ゆえ、
旗艦他スリーブと同格（未認定タグ）での採用が妥当。認定には期間延長（2016前不可）か breadth 拡大が要る。

### 7.2 top-300 ほぼ完全化での最終判定（306銘柄・2026-06-28）
所有取得を **top-300 の 299/300**（unmappable 1・no-data 数件）まで完成。**本節が最終結果（§7/§7.1 を上書き）**。

| strategy (306名) | net年率SR | DSR | 容量 |
|---|--:|--:|--:|
| pead_lowADV(size) | +0.36 | **0.42** | ¥821万 |
| pead_xF | +0.33 | 0.40 | ¥515万 |
| pead_lowF(低外国人) | +0.32 | 0.37 | ¥846万 |
| pead_highIndiv | +0.21 | 0.24 | ¥616万 |
| pead_all(基準) | +0.03 | 0.12 | ¥1642万 |
| pead_highF(対照) | −0.46 | 0.00 | ¥616万 |

**判定＝❌ FAIL**（最良 pead_lowADV DSR=0.42<0.95）。

**ユニバースサイズ横断のロバストネス（160→263→306）＝この研究の最重要メタ所見**:
| 比較 | 160名 | 263名 | 306名 |
|---|--:|--:|--:|
| pead_lowF (低外国人) | +0.22 | +0.19 | +0.32 |
| pead_lowADV (size) | +0.21 | +0.11 | +0.36 |
| **lowF − lowADV** | **≈0** | **+0.08** | **−0.04** |

→ **H2（foreign-beyond-size）は頑健でない**：lowF vs lowADV の優劣が標本で反転。§7.1 の「H2支持」は**263名標本に特有**で、完成データで**取り消し**。容量優位（263名で lowF¥740万≫size¥22万）も306名で消滅（両者¥800万級）＝あれも標本依存。

**頑健に残る所見（全サイズで不変）**:
1. **条件付けは効く**：low-foreign / low-ADV / xF すべて素PEAD（≈0）を明確に上回る。
2. **高外国人は一貫して強い負**（−0.45 / −0.45 / −0.46）＝PEAD は高外国人で**反転**。
3. **素PEAD（流動top300全体）は希釈で ≈0〜負**。

### 最終結論（過大主張しない）
- **論文の定性（PEAD は低外国人/高個人で持続・高外国人で消失/反転）は本リポでも頑健に再現**。
- だが **foreign% の size 超過分は頑健でなく**（標本で反転）、**認定は未達**（最良 DSR0.42・直近集中）。
  ＝精緻化の正味は **「PEAD を低外国人/小型へ傾け、高外国人を除外」**＝実質 **size×ownership 共通の“非効率帯”への集中**で、
  これは size（PIT で FAIL 済）と不可分。**独立した認定アルファではない**。
- **行動可能で頑健な唯一の核**＝**PEAD 脚から「高外国人（≒効率的に価格形成される大型）」を除外/縮小**（一貫した負ドリフトの除去
  ＝リスク管理として妥当）。未認定タグ付きで旗艦 PEAD 脚へ反映する価値はあるが、認定アップグレードではない。
- **教訓**: 263名で見えた「foreign>size・容量優位」は**データ未完成ゆえの標本効果**だった。ユニバース完成（step3）が
  過大主張を防いだ＝検証規律の実例。

## 8. 実装（高外国人除外オーバーレイ・**既定 OFF**）

§7 の唯一の頑健核（高外国人＝一貫した負ドリフト）を、旗艦 PEAD スリーブの**任意フック**として実装。
**未認定タグ付き・既定 OFF＝no-op**（本番ナイトリーは現行と完全一致）。フォワードテスト候補であって認定改良ではない。

- **モジュール**: `invest_system/equities/ownership.py`（純関数）。
  - `load_ownership()` → 銘柄別 median 所有（持続値）。`high_foreign_codes(own, cutoff_q)` → 高外国人集合。
  - `apply_high_foreign_exclusion(signal, own=None, *, enabled=False, cutoff_q=0.67, mode="exclude", shrink=0.0)`
    ＝PEADシグナル(Date×Code)から高外国人列を NaN（除外）or 減量。**所有不明は保持（graceful）**。
- **フック（既定OFF）**: `examples/phase2_generate_orders.py`（**本番**）と `examples/research_value_pead_longtilt.py`
  の PEAD シグナル構築直後に1行。フラグ `J_PEAD_FX_EXCLUDE`（既定 `0`＝OFF）、`J_PEAD_FX_CUTOFF_Q`（既定 0.67）。
  **OFF のとき出力は現行とバイト一致**＝本番無影響。所有パネルが無ければ自動 no-op（新規必須依存を作らない）。
- **テスト**: `tests/test_ownership_overlay.py`（OFFで恒等／ON除外／減量／所有欠損で no-op／unknown保持／cutoff）。
- **データ依存と本番有効化パス**: 所有は年1回・粘着的ゆえ、本番は**キャッシュ parquet を読むだけ**（毎晩取得不要）。
  恒久ONは (1) 所有パネルの定期/自動リフレッシュ（理想＝`data/edinet/docs` から所有者別状況をオフライン抽出する
  ローカル抽出器＝MCP/API非依存・CI互換）＋(2) フラグ ON、が整ってから。それまでは研究/フォワード用に OFF 既定。
- **限界**: 未認定（DSR0.42）・foreign≈size。リスク管理（負ドリフト帯の除去）として妥当だが独立αではない。

### 8.1 オフライン所有抽出器（本番フィード化・実装済み 2026-06-28）

- **カバレッジ: 4,387社 / 27,699 社×年**（MCP の306を桁違いに上回る＝市場ほぼ全域・約10年）。quality ok 27,454。
- **MCP 照合（正しさの裏取り）**: overlap 2,017行で **|Δforeign_pct| 中央0.00pt・平均0.07pt・≤1pt 99%**＝

  （新規 doc のみ処理・ネット不要）。深度は EDINET doc ミラー（既存取得パイプライン）に律速。
