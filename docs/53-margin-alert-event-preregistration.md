## §2 事前登録（固定・実行前コミット）

### §2.1 仮説（方向を事前固定）
- **H1**: 増担保規制の**指定**（Restricted 0→1）後、対象銘柄は 5〜10営業日アンダーパフォーム
  （新規信用買いの強制遮断→投機需要消滅→需給悪化のドリフト）。
- **H2**: 増担保規制の**解除**（Restricted 1→0）後、対象銘柄は 5〜10営業日アウトパフォーム
  （信用買い再開・需給正常化の安堵）。
- **H3**: 日々公表の指定/解除（マイルドな前段措置）にも同方向の弱いドリフト。

### §2.2 経済的根拠
増担保規制は証拠金率引き上げで信用買いの限界需要を**制度的に**遮断する（行動でなく規制の機構）。
指定は過熱（急騰・信用買い急増）の後に来るため、モメンタム反転と混同しないよう
イベント日アンカー＋ドルニュートラルで検定する。解除は制約の解放＝需要回復。

### §2.3 データと PIT 規律（チェックリスト確認済み）
- シグナル: `PubDate` ≤ t の margin_alert フラグ遷移のみ。執行 `execution_lag=1`（T+1）。
- ユニバース: 普通株（`filter_common_stocks`）∧ PIT eligible（trailing252日≥120日約定）。
- 値幅ロック `limit_lock_flags` 適用・ADV=trailing turnover・participation=0.1。
- 上場廃止: wide パネル脱落＝ポジション消滅（docs/48 と同処理）。既知の限界に記載。
- OOS(2024-01+) は設計・セル選択に不使用（診断でのみ表示）。

### §2.6 合格基準（事前固定）
1. **DSR ≥ 0.95**（唯一の主基準・大域デフレート）
2. 副次（PASS の追加条件）: 最良セルの net SR > 0 かつ サブ期間（judge 3分割）の符号が 2/3 以上正
   かつ 容量 ≥ ¥5,000万
3. 上記未達は機械的に FAIL。事後救済なし（符号逆・別セル基準への差替え禁止）

### §2.7 既知の限界（正直に）
- 貸株300bps は保守仮定（実勢逆日歩は JSF 未統合＝docs/49）。sweep で損益分岐を露出する。
- 規制指定銘柄は急騰後が多く、ショート脚は「高値からの反転」成分を含み得る（F4 近傍）。
  ρ̄（vs momentum/value 因子リターン）を診断で必須報告。
- 上場廃止はパネル脱落処理（イベント銘柄の廃止バイアスは軽微と想定するが未補正）。
- 日々公表→増担保は段階遷移のため H1 と H3 のイベントは部分的に重複し得る（セルは独立に判定）。
