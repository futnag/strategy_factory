## §2 事前登録（固定・実行前コミット）

### §2.1 仮説（方向を事前固定）
- **H1（主）**: コホートは実施日翌営業日から数週間でサイズマッチ統制を**上回る**（リバーサル）。
  方向は明田(2022) で事前固定（コホート・ロング）。
- **H2（機構）**: 実施日近傍（[0,1]）ではコホートは統制を**下回る**（一時的売り圧力）。
- **H3（統制・H-18）**: スケジュール終了後（2025-04以降）の四半期末では H1 効果は**消える**。

### §2.2 経済的根拠
公表スケジュール済みの機械的インデックス売り（四半期末×10段階・低減幅と対象が事前公知）は、
実施日に一時的な価格圧力を生み、指値供給者がその在庫リスクにプレミアムを得て数週間で価格が
復元する。情報の非対称性でなくカレンダー付き強制フロー＝uninformed な純供給（H-17 適合）。

### §2.3 データと PIT 規律（チェックリスト確認済み）
- シグナル ≤t: 実施日・コホートは公表済み（2022-10-07/2023-10-06）＝完全に事前既知。
- 執行 T+1: `execution_lag=1`（実施日 t の翌営業日始値でエントリ）。
- PIT ユニバース: 各時点で普通株・流動性フィルタ（trailing 252 の traded≥120）。
- 上場廃止: forward return は panel の NaN 伝播で自然処理（イベント窓外は現金）。
- OOS 不使用: 設計・グリッドは明田＋スケジュール規則のみ由来（ローカルOOS を設計に使わない）。
- kaiten 系不使用。
