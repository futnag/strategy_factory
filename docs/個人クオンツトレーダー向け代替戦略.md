1. Systematic Factor Investing

内容: 低回転（月次〜四半期リバランス）で、Value + Quality + Profitabilityを組み合わせたロングオンリーのファクター戦略。
なぜ個人に向くか:
バックテストの再現性が高く、過剰適合しにくい。
取引コストが非常に低い（特にETF経由 or 流動性高い銘柄に絞る）。
López de Pradoの手法（purged CV、Deflated Sharpeなど）がそのまま活きる。
NISAとの相性も良い。

日本での実践例: TSEの低PBR改革を活用した「低PBR + 改善計画開示 + ROE向上」スクリーニング。米国ではAVUVやDFSVのようなSmart Beta ETFを参考に自前で構築。
課題: リターンは控えめ（年5-12%程度が現実的）。「派手さ」は少ない。

2. Trend Following（トレンドフォロー） / Managed Futures

内容: 先物（株式指数、コモディティ、債券、為替）でシンプルなトレンドフォロー（移動平均ブレイクアウトやモメンタム）。
なぜ個人に向くか:
株式との相関が低く、ポートフォリオ全体の安定化に寄与しやすい。
データがクリーンでバックテストしやすい。
Ernie Chanや他のクオンツ本でよく取り上げられる領域。
1日1回のシグナルで十分に運用可能。

あなたの適性: 非常に高い。システム構築がしやすく、心理的負担も比較的少ない。
課題: 長期のレンジ相場でドローダウンが長引く可能性あり。レバレッジを使う場合はリスク管理が重要。

3. 日本企業イベントドリブン戦略

内容: 自社株買い発表、MBO・TOB、親子上場解消、業績修正（ガイダンス上方修正）、株主優待新設などを体系的に捉える。
なぜ日本在住のあなたに向くか:
EDINET + TDnet + J-Quantsの組み合わせで情報優位性が出しやすい。
海外のクオンツがなかなか手を出さない領域。
比較的低回転で済む。

強み: あなたの立地（大阪）と日本語能力が明確な優位性になる。
課題: イベントの発生頻度が不規則。シグナルがスパースになりやすい。

4. Statistical Arbitrage / Pairs Trading

内容: 相関の高い銘柄ペアやセクター内で平均回帰を狙う（Cointegrationベース）。
利点: 市場全体の方向に依存しにくい（市場中立に近い）。
あなたの適性: 統計的アプローチが好きな人に合いやすい。Pythonでの実装も比較的ストレート。
課題: ペアの安定性が崩れやすい（regime changeに弱い）。監視コストがかかる。

5. Systematic Volatility Premium（ボラ売り）

内容: VIX関連商品や個別株オプションで、体系的にプレミアムを売り抜く（Iron Condor、Short Strangleなどルール化）。
利点: 時間経過による利益（Theta）が期待できる。
課題: テールリスクが大きい（2020年3月のようなイベントで大損する可能性）。オプションの知識と証拠金管理が必要。
