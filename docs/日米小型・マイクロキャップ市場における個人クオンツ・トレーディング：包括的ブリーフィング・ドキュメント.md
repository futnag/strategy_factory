日米小型・マイクロキャップ市場における個人クオンツ・トレーディング：包括的ブリーフィング・ドキュメント

エグゼクティブ・サマリー

本資料は、個人投資家が日米の小型・マイクロキャップ株式市場においてクオンツ（計量的）戦略を構築・実行するための技術的要件、統計的エッジ、およびリスク管理に関する分析をまとめたものである。

主要な結論として、個人クオンツの唯一にして最大の「堀（モート）」は、機関投資家が物理的に参入不可能な低流動性銘柄におけるキャパシティの制約にある。マイクロキャップ市場では、月額50〜100ドルの低予算インフラで、日米両市場を網羅するスキャナー構築が可能である。しかし、紙上のアルファの大部分は、マイクロキャップ特有の膨大な取引コスト（往復200bps以上）や生存者バイアス、過剰適合によって消滅する。

成功の鍵は、高度なアルゴリズムよりも、**「生存者バイアスを排除したデータ」「厳格なコスト・モデリング」「自己欺瞞を防ぐ統計的検証（DSR/PBO）」**の3点にある。ポートフォリオは、インデックス等のコア（85%）と、検証済みのクオンツ戦略であるサテライト（15%）に分割する構成が推奨される。

1. クオンツ・インフラの構築とデータ戦略

月額50〜100ドルの予算内で、数千の銘柄をカバーする日米横断型のクオンツ・スキャナーを構築することは十分に可能である。

1.1 推奨データスタックとコスト構成例

データ費用を最小限に抑えつつ、品質を確保するための構成は以下の通りである。

項目	選択肢	推定月額	備考
米国データ	Tiingo Power または Polygon Starter	$29〜30	EOD（終値）ベース。マイクロキャップ/OTCを網羅

1.2 データエンジニアリングの要所

* 生存者バイアスの排除: 現在上場している銘柄のみでバックテストを行うと、過去の倒産・上場廃止銘柄が無視され、リターンが劇的に過大評価される。Norgate DataやSharadar、J-Quantsのように上場廃止銘柄を含むソースの利用が不可欠である。
* ポイント・イン・タイム（PIT）: 財務データは「発表された瞬間」のタイムスタンプを使用する必要がある。修正後の財務諸表を使用すると、将来の情報を知っていることになる「先読みバイアス」が生じる。
* DuckDB + Polars: 数千銘柄の時系列データを処理するには、従来のPostgreSQL等よりも、Parquetファイルを直接クエリできるDuckDBや、メモリ効率の良いPolarsが適している。

2. 統計的エッジと市場特性：日米の比較

日米の市場構造は大きく異なり、それぞれに最適化された戦略が必要となる。

2.1 米国市場：モメンタムとPEAD

* 52週高値モメンタム: 52週高値に近い銘柄をロングする戦略は、従来の中期モメンタム（12-2ヶ月）よりも低回転かつ堅牢である。
* PEAD（決算後のドリフト）: 期待を上回る決算（SUE）を発表した小型株は、情報拡散の遅れにより数週間にわたって価格がドリフトする傾向がある。

2.2 日本市場：リバーサルとバリュー

* リバーサルの支配: 米国と異なり、日本市場はモメンタムが弱く、1ヶ月リバーサル（逆張り）が支配的である。特にTSE Growth（旧マザーズ）のような個人主体かつアナリスト・カバーが少ない市場で顕著である。
* 東証のガバナンス改革: 低PBR銘柄への改善要求や自社株買い、親子上場解消などのイベント・ドリブンな戦略が有効なバイアスとなっている。
* 特殊な制約: 日本市場特有の「ストップ高・安」の価格制限や、100株単位の売買、ティックサイズの違いをバックテストに組み込む必要がある。

3. バックテストの厳格化と自己欺瞞の回避

学術調査によると、公表されたアノマリーの約65%は再現不可能であり、その多くはPハッキング（多重テスト）による「偽の発見」である。

3.1 Lopez de Pradoのツールキット

個人トレーダーが過剰適合（オーバーフィッティング）を避けるための必須手法は以下の通りである。

1. Purged K-Fold Cross-Validation: 時系列データの重なりによるリーク（漏洩）を防ぐため、訓練データとテストデータの間に「Informational Air Gap（情報の空隙）」を設ける。
2. Deflated Sharpe Ratio (DSR): テストした戦略の数（N）を考慮に入れ、シャープレシオを割り引く。200通りのパラメータを試した場合、見かけ上高いリターンは単なる偶然である可能性が高い。
3. Meta-Labeling: 第一のモデルが「売買の方向」を決め、第二のMLモデルがその予測の「信頼度（確率）」を判断してポジションサイズを調整する。

3.2 摩擦係数の現実的モデリング

マイクロキャップ戦略を殺すのはアルゴリズムの弱さではなく、取引コストである。

* ビッド・アスク・スプレッド: 超小型株では往復で5%を超えることもある。終値での約定を前提にせず、スプレッドの半分をコストとして差し引く必要がある。
* マーケット・インパクト: 自分の注文が価格を動かしてしまう現象。ADV（一日平均売買代金）の1〜5%以内に注文を抑える制約が必要である。

4. リスク管理とポジションサイジング

マイクロキャップのボラティリティは極めて高く、破産を避けるための数学的規律が求められる。

4.1 分数ケリー基準（Fractional Kelly）

幾何学的成長を最大化するケリー基準は、推定値に誤りがあると容易に破産を招く。

* 1/4ケリーの推奨: 推定されたケリー分数の25%程度をポジションサイズとして使用することで、リターンの75%を維持しつつ、ドローダウンを劇的に抑制できる。
* 高次モーメントの調整: マイクロキャップのリターン分布は歪度（Skewness）と尖度（Kurtosis）が大きいため、ガウス分布を前提とした標準的な計算を修正し、負の歪度（急落リスク）に対してはサイズを縮小すべきである。

4.2 ドローダウン・サーキットブレーカー

* スリーブ・レベルの停止: 戦略全体のドローダウンが15%に達した時点でポジションを縮小し、25〜30%で完全停止・再検証を行うというルールを事前に自動化しておく。
* ADV制約: ケリー基準が「総資金の10%を賭けろ」と言ったとしても、その銘柄のADVの1%を超えるなら、ADV制限を優先する。

5. 個人クオンツの倫理と現実

学術的根拠に基づくと、アクティブに取引する個人投資家の約97〜99%は、最終的にインデックスに劣後するか、資金を失う。

5.1 成功のテンプレート

生き残っているトレーダー（例：Mike "Huddie" Hudson）に共通する特性は以下の通りである。

* ニッチへの集中: 大手ファンドが運用規模の都合で触れない「不効率なゴミ山」の中で、体系的にショート（またはロング）を行う。
* 強固なリスク管理: 1トレードあたりのリスクを純資産の1%以下に抑え、1日の最大損失額に達したら即座に画面を閉じる規律。
* 検証の検証: バックテストの結果を信じず、常にコストやバイアスを疑い、実運用（ライブ）の滑りがバックテストと一致するかを数ヶ月単位で観察する。

5.2 最終的な推奨事項

1. コア・サテライト運用の徹底: 資産の85%は低コストなインデックスファンドで運用し、クオンツ戦略（サテライト）は最大15%に限定する。
2. ペーパートレードの先行: リアルマネーを投入する前に、少なくとも3ヶ月間はフォワードテストを行い、約定価格の乖離を確認する。
3. シンプルさを保つ: 複雑なディープラーニングよりも、データのクレンジングと、堅牢なファンダメンタルズ/モメンタムのルールを優先する。

警告: 小型株およびマイクロキャップ投資は、流動性の欠如、情報の非対称性、および高いボラティリティを伴う。本ドキュメントに記載された手法やデータは、投資成果を保証するものではなく、実行にあたっては全ての責任を投資家自身が負うものとする。
