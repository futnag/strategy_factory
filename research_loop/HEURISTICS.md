## H-1 momentum 代理チェック — active
シグナルが momentum(12-1) の単調変換・高相関（ρ̄>0.3）なら独立エッジではない。Stage-0 で
相関見込みを見積り、超えるなら kill か残差化を設計に組み込む。
**証拠**: high_52w（ρ̄+0.38・DSR0.67）、macro_sector_rotation（ρ̄+0.32・DSR0.56）＝docs/03 §6.20。

## H-2 value／PBR改革レジーム共変チェック — active
サブ期間で 2016-19・2019-23 が無効、**2023-26 のみ正**の候補は、独立プレミアではなく
資本規律（PBR改革）レジームで value と同根の共変である疑いが強い。
**証拠**: asset_growth（DSR0.78・vs value ρ̄+0.22・2023-26 +1.59 のみ）＝TODO.md ④／docs/03 §6.20。

## H-3 コスト損益分岐の事前計算 — active
月次クロスセクション＠15bps は成立余地あり。**日次・小型イベント系は片道25bps が実測の死線**。
Stage-0 で「想定回転×現実スプレッド < 想定 gross」を必ず概算。gross が強くても
スプレッドで死ぬ（紙上α）。
**証拠**: limit_reversal（gross SR+1.08 → net 負・損益分岐≈片道25bps・容量¥0.2百万・DSR0.26）＝docs/48 §5。

## H-4 minTRL／MinBTL 実現可能性チェック — active
SR~0.4 の単独因子は minTRL≈20年＝現有10年の履歴では**構造的に認定不能**。月次×単一系列は
n_obs 不足で同様。単独低SR因子より、breadth（多銘柄横断）・イベント（多発事象）・
既存スリーブへのオーバーレイを優先する。
**証拠**: value 単独（SR~0.36・minTRL≈241ヶ月・DSR0.82 止まり）＝docs/03 §7.1／judge.py docstring の警告。

## H-5 de-risk 形状テスト — active
タイミング／ゲート系は DD を減らすだけで Sharpe を改善しないことが多い（α ではなく露出調整）。
**買い持ちベンチマーク超過**を事前登録の副次基準に必ず入れる。建玉率相当のランダム建玉とも比較。
**証拠**: option_regime_topix（SR+0.45 < 買い持ち+0.66・DSR0.83）、flow_divergence_topix
（+0.40 < +0.75・DSR0.56）＝docs/03 §6.20。

## H-6 独立性は必要条件であって十分条件でない — active
vs value/momentum/size の ρ̄≈0 は「新しい軸」の証明であって「エッジがある」証明ではない。
独立性だけを理由に優先度を上げない（機構の強さの証拠を別途要求する）。
**証拠**: disclosure_text_change（ρ̄≈0 だが SR≈0・DSR0.36/0.44）、dso_quality（独立だが符号逆・DSR0.12）＝docs/03 §6.20-6.21。

## H-7 ショート脚の構造衝突チェック — active
下方修正・ディストレス・割安銘柄のショートは value のロング側と正面衝突する（2024+ の
バリュー復権で反発を食らう）。ショートに依存する設計は脚分解を事前登録に含め、
ロングティルト（市場ヘッジ）代替を最初から検討する。
**証拠**: PEAD ショート脚崩壊（−2.50%→+3.00%）→ ロングティルト化で解決＝docs/03 §7.2-7.3。

**目的関数の選択**（予測 → 価格付け/SDF 型）の方が有効な自由度だった。
**証拠**: conditional_sdf Stage2（deep GRU DSR0.12・GRU≡Linear）／H1 収穫（KNS-SDF +0.38 >

## H-12 ポートフォリオSR上限の Stage-0 概算（breadth×ボラ×想定ドリフト） — active
イベント系は事前に SR上限 ≈（想定日次ドリフト／対象銘柄の日次ボラ）×√実効breadth を概算する。
実効breadth＝日次同時イベント数（保有窓内）。同時1〜5銘柄×日次ボラ5〜10%では、ドリフトが
実在しても（数十bps/日規模でない限り）SR にならず、容量も participation 制約で¥万単位に落ちる。
リターン方向を覗かずに計算できる（イベント件数・銘柄ボラ・仮定ドリフトのみ）＝K=0 で合法。
**証拠**: margin_alert_event（記述ドリフト−140〜−394bps/10日は実在、最良 gross+1.33 でも
DSR0.01・容量¥7万）＝docs/53 §5。limit_reversal（docs/48）と対で「イベント系の死因2型」を構成。

## H-15 米国リスクプレミアム系 XS 発見は日本で符号ごと反転しがち — active
米国データで文書化されたリスクプレミアム型クロスセクション効果（特にボラ・ベータ・テール・
低リスク系）は、日本 2016+ では符号反転または消滅する系譜が確立している。米国証拠だけで
方向を固定する場合、Stage-0 で「日本での直接証拠の有無」を確認し、無ければ（a）実効試行数が
2倍（両方向）である前提で K 予算・期待値を見積る、（b）グリッドを最小化する、（c）日本固有の
機構説明（なぜ日本でも同方向のはず）を経済的根拠に明記できないなら優先度を下げる。
**証拠**: BAB 符号逆（low_risk_anomaly・低ベータ SR−0.7＝docs/03 §6.20）、ジャンプテールβ
符号逆（jump_tail_beta_xs・全セル負だが急落月全勝＝保険の向きが逆・docs/55 §5）、
日本のモメンタム弱（§6.7）。

## H-14 既存スリーブの「改良研究」は standalone DSR では裁けない — active
稼働スリーブの設計変種（シグナル写像・速度・重み付けの改良）はベースラインと高相関（ρ0.8+）に
なるため、変種の standalone DSR はベースラインの DSR に張り付き、改良幅が劇的でない限り
認定（DSR≥0.95）に構造的に届かない。改良仮説を採る場合は Stage-0 で（a）期待改良幅が単独認定級か、
（b）差分系列/スパニング枠（I-16 導入後）で裁けるか、（c）判定でなく本番運用側の人間判断事項
（proposals 相当）か、を先に仕分けること。「僅差の改良＋認定未達」は予見可能な結末。
**証拠**: trend_structure（最良 tanh が全リスク指標で 12-1 を支配しつつ DSR0.92 で FAIL・
ベースライン相関0.86）＝docs/54 §5。

## H-13 規制・注意喚起の「解除」は回復シグナルでない — active
増担保規制・日々公表の解除後も対象銘柄は下落を継続する（解除は過熱冷却の完了宣言でなく
途中経過＝投機の脱気が続く）。「解除＝需給正常化の安堵ラリー」型の仮説は方向を逆に登録しがち。
制度イベントの解除側をロングで仮説化する場合は、この prior に反する強い根拠を要求する。
**証拠**: margin_alert_event（Restricted 解除後 −566bps/10日・n=772、DailyPublication 解除後
−108bps/10日・n=2573。解除ロング3セル net SR −1.7〜−2.0）＝docs/53 §5。
