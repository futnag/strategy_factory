## H-1 momentum 代理チェック — active
シグナルが momentum(12-1) の単調変換・高相関（ρ̄>0.3）なら独立エッジではない。Stage-0 で
相関見込みを見積り、超えるなら kill か残差化を設計に組み込む。
**証拠**: high_52w（ρ̄+0.38・DSR0.67）、macro_sector_rotation（ρ̄+0.32・DSR0.56）＝docs/03 §6.20。

## H-2 value／PBR改革レジーム共変チェック — active
サブ期間で 2016-19・2019-23 が無効、**2023-26 のみ正**の候補は、独立プレミアではなく
資本規律（PBR改革）レジームで value と同根の共変である疑いが強い。
**証拠**: asset_growth（DSR0.78・vs value ρ̄+0.22・2023-26 +1.59 のみ）＝TODO.md ④／docs/03 §6.20。

## H-3 コスト損益分岐の事前計算 — active
月次クロスセクション＠15bps は成立余地あり。**日次・小型イベント系は片道25bps が実測の死線**。
Stage-0 で「想定回転×現実スプレッド < 想定 gross」を必ず概算。gross が強くても
スプレッドで死ぬ（紙上α）。
**証拠**: limit_reversal（gross SR+1.08 → net 負・損益分岐≈片道25bps・容量¥0.2百万・DSR0.26）＝docs/48 §5。

## H-4 minTRL／MinBTL 実現可能性チェック — active
SR~0.4 の単独因子は minTRL≈20年＝現有10年の履歴では**構造的に認定不能**。月次×単一系列は
n_obs 不足で同様。単独低SR因子より、breadth（多銘柄横断）・イベント（多発事象）・
既存スリーブへのオーバーレイを優先する。
**証拠**: value 単独（SR~0.36・minTRL≈241ヶ月・DSR0.82 止まり）＝docs/03 §7.1／judge.py docstring の警告。

## H-5 de-risk 形状テスト — active
タイミング／ゲート系は DD を減らすだけで Sharpe を改善しないことが多い（α ではなく露出調整）。
**買い持ちベンチマーク超過**を事前登録の副次基準に必ず入れる。建玉率相当のランダム建玉とも比較。
**証拠**: option_regime_topix（SR+0.45 < 買い持ち+0.66・DSR0.83）、flow_divergence_topix
（+0.40 < +0.75・DSR0.56）＝docs/03 §6.20。

## H-6 独立性は必要条件であって十分条件でない — active
vs value/momentum/size の ρ̄≈0 は「新しい軸」の証明であって「エッジがある」証明ではない。
独立性だけを理由に優先度を上げない（機構の強さの証拠を別途要求する）。
**証拠**: disclosure_text_change（ρ̄≈0 だが SR≈0・DSR0.36/0.44）、dso_quality（独立だが符号逆・DSR0.12）＝docs/03 §6.20-6.21。

## H-7 ショート脚の構造衝突チェック — active
下方修正・ディストレス・割安銘柄のショートは value のロング側と正面衝突する（2024+ の
バリュー復権で反発を食らう）。ショートに依存する設計は脚分解を事前登録に含め、
ロングティルト（市場ヘッジ）代替を最初から検討する。
**証拠**: PEAD ショート脚崩壊（−2.50%→+3.00%）→ ロングティルト化で解決＝docs/03 §7.2-7.3。

## H-8 データ制約の事前確認 — active

TDnet・ToSTNeT・JSF。**docs/24 と突合してから**事前登録する（走らせてから気づくのは⑦型の失敗）。
**証拠**: bond_term_carry（分散キャリー構築不能・DSR0.25）＝TODO.md ⑦／docs/03 §6.20。

## H-9 古データ減衰チェック — active

既に死んでいる。サブ期間の単調減衰＋OOS 負は不採用サイン。
**証拠**: margin_overhang（2016-19 +1.15 → 2023-26 −0.07・IS+0.92→OOS−0.33・DSR0.75）＝TODO.md ⑤。
